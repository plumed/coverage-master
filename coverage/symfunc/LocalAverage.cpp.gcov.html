      35             : //+PLUMEDOC MCOLVARF LOCAL_AVERAGE
      36             : /*
      37             : Calculate averages over spherical regions centered on atoms
      38             : 
      39             : As is explained in <a href="http://www.youtube.com/watch?v=iDvZmbWE5ps"> this video </a> certain PLUMED actions
      40             : calculate one scalar quantity or one vector for each of the atoms in the system.  For example
      41             : [COORDINATIONNUMBER](COORDINATIONNUMBER.md) measures the coordination number of each of the atoms in the system and [Q4](Q4.md) measures
      42             : the 4th order Steinhardt parameter for each of the atoms in the system.  These quantities provide tell us something about
      43             : the disposition of the atoms in the first coordination sphere of each of the atoms of interest.  In the paper in the bibliography Lechner and Dellago
      44             : have suggested that one can probe local order in a system by taking the average value of such symmetry functions over
      45             : the atoms within a spherical cutoff of each of these atoms in the systems.  When this is done with Steinhardt parameters
      46             : they claim this gives a coordinate that is better able to distinguish solid and liquid configurations of Lennard-Jones atoms.
      47             : 
      48             : You can calculate such locally averaged quantities within plumed by using the LOCAL_AVERAGE command.  This command calculates
      49             : the following atom-centered quantities:
      50             : 
      51             : $$
      52             : s_i = \frac{ c_i + \sum_j \sigma(r_{ij})c_j }{ 1 + \sum_j \sigma(r_{ij}) }
      53             : $$
      54             : 
      55             : where the $c_i$ and $c_j$ values can be any vector of [symmetry functions](https://www.plumed-tutorials.org/lessons/23/001/data/SymmetryFunction.html)
      56             :  that can be calculated using plumed multicolvars.  The function $\sigma( r_{ij} )$ is a switching function that acts on the distance between
      57             : atoms $i$ and $j$.  Lechner and Dellago suggest that the parameters of this function should be set so that it the function is equal to one
      58             : when atom $j$ is in the first coordination sphere of atom $i$ and is zero otherwise.
      59             : 
      60             : To see how this works in practice consider the following example input.
      61             : 
      62             : ```plumed
      63             : d1: COORDINATIONNUMBER SPECIES=1-64 SWITCH={RATIONAL D_0=1.3 R_0=0.2 D_MAX=3.0}
      64             : la: LOCAL_AVERAGE SPECIES=d1 D_0=1.3 R_0=0.2 NN=6 MM=12
      65             : mtf: MORE_THAN ARG=la SWITCH={RATIONAL R_0=4}
      66             : la_morethan: SUM ARG=mtf PERIODIC=NO
      67             : PRINT ARG=la_morethan FILE=colvar
      68             : ```
      69             : 
      70             : This input calculates the coordination numbers for all the atoms in the system.  These coordination numbers are then averaged over
      71             : spherical regions.  The number of averaged coordination numbers that are greater than 4 is then output to a file.  Furthermore, if you
      72             : expand the input above you can see how the LOCAL_AVERAGE command is a shortcut action that expands to a longer input that you should be able to
      73             : interpret.
      74             : 
      75             : In the input above we use a rational [switching function](LESS_THAN.md) with the parameters above. We would recommend using SWITCH syntax
      76             : rather than the syntax above when giving the parameters for the switching function as you can then use any of the switching functions described
      77             : in the documentation for [LESS_THAN](LESS_THAN.md).  More importantly, however, using this syntax allows you to set the D_MAX parameter for the
      78             : switching function as demonstrated below:
      79             : 
      80             : ```plumed
      81             : d1: COORDINATIONNUMBER SPECIES=1-64 SWITCH={RATIONAL D_0=1.3 R_0=0.2 D_MAX=3.0}
      82             : la: LOCAL_AVERAGE SPECIES=d1 SWITCH={RATIONAL D_0=1.3 R_0=0.2 D_MAX=3.0}
      83             : mtf: MORE_THAN ARG=la SWITCH={RATIONAL R_0=4}
      84             : la_morethan: SUM ARG=mtf PERIODIC=NO
      85             : PRINT ARG=la_morethan FILE=colvar
      86             : ```
      87             : 
      88             : Setting the `D_MAX` can substantially improve PLUMED performance as it turns on the linked list algorithm that is discussed in the optimisation details part
      89             : of the documentation for [CONTACT_MATRIX](CONTACT_MATRIX.md).
      90             : 
      91             : ## Locally averaged Steinhardt Parameters
      92             : 
      93             : What Lechner and Dellago did in their paper was a little more complicated than the example in the previous section. To reproduce what they did you would use
      94             : an input something like this:
      95             : 
      96             : ```plumed
      97             : q4: Q4 SPECIES=1-64 SWITCH={RATIONAL D_0=1.3 R_0=0.2}
      98             : la: LOCAL_AVERAGE SPECIES=q4 SWITCH={RATIONAL D_0=1.3 R_0=0.2}
      99             : la_mean: MEAN ARG=la PERIODIC=NO
     100             : PRINT ARG=la_mean FILE=colvar
     101             : ```
     102             : 
     103             : This example input calculates the [Q4](Q4.md) vectors for each of the atoms in the system.  These vectors are then averaged
     104             : component by component over a spherical region.  The average value for this quantity is then outputeed to a file.  If you want
     105             : to understand more about the shortcut that is used here you can read [this page](https://www.plumed-tutorials.org/lessons/23/001/data/Steinhardt.html).
     106             : 
     107             : ## Using SPECIESA/SPECIESB
     108             : 
     109             : If you only want to calculate the local averages for a subset of the atoms you might use an input like the one shown below:
     110             : 
     111             : ```plumed
     112             : # Calculate the coordination numbers for the two types of atom
     113             : d1a: COORDINATIONNUMBER SPECIES=1-5 SWITCH={RATIONAL D_0=1.3 R_0=0.2 D_MAX=3.0}
     114             : d1b: COORDINATIONNUMBER SPECIES=1-64 SWITCH={RATIONAL D_0=1.3 R_0=0.2 D_MAX=3.0}
     115             : # Now compute the local average
     116             : la: LOCAL_AVERAGE SPECIESA=d1a SPECIESB=d1b SWITCH={RATIONAL D_0=1.3 R_0=0.2 D_MAX=3.0}
     117             : DUMPATOMS ARG=la ATOMS=1-5 FILE=atoms.xyz
     118             : ```
     119             : 
     120             : In the input above the local averages are computed for atoms 1-5 only. However, to calculate these local averages we still need to calculate the coordination numbers of all
     121             : the atoms in the system.
     122             : 
     123             : ## The MASK keyword
     124             : 
     125             : You can use the MASK keyword with this action in the same way that it is used with [COORDINATIONNUMBER](COORDINATIONNUMBER.md).  This keyword thus expects a vector in
     126             : input, which tells PLUMED the atoms for which you do not need to calculate the function.  As illustrated below, this is useful if you are using functionality
     127             : from the [volumes module](module_volumes.md) to calculate the average value of the local averages for only those atoms that
     128             : lie in a certain part of the simulation box.
     129             : 
     130             : ```plumed
     131             : # Calculate the coordination number for all the atoms
     132             : cc: COORDINATIONNUMBER SPECIES=1-400 SWITCH={RATIONAL D_0=1.3 R_0=0.2 D_MAX=3.0}
     133             : # Fixed virtual atom which serves as the probe volume's center (pos. in nm)
     134             : center: FIXEDATOM AT=2.5,2.5,2.5
     135             : # Vector in which element i is one if atom i is in sphere of interest and zero otherwise
     136             : sphere: INSPHERE ATOMS=1-400 CENTER=center RADIUS={GAUSSIAN D_0=0.5 R_0=0.01 D_MAX=0.52}
     137             : # Calculate the local average
     138             : lcc: LOCAL_AVERAGE SPECIES=cc SWITCH={RATIONAL D_0=1.3 R_0=0.2 D_MAX=3.0} MASK=sphere
     139             : # Multiply local averages parameters numbers by sphere vector
     140             : prod: CUSTOM ARG=lcc,sphere FUNC=x*y PERIODIC=NO
     141             : # Sum of coordination numbers for atoms that are in the sphere of interest
     142             : numer: SUM ARG=prod PERIODIC=NO
     143             : # Number of atoms that are in sphere of interest
     144             : denom: SUM ARG=sphere PERIODIC=NO
     145             : # Average coordination number for atoms in sphere of interest
     146             : av: CUSTOM ARG=numer,denom FUNC=x/y PERIODIC=NO
     147             : # And print out final CV to a file
     148             : PRINT ARG=av FILE=colvar STRIDE=1
     149             : ```
     150             : 
     151             : This input calculates the average value of the local average for those atoms that are within a spherical region that is centered on the point $(2.5,2.5,2.5)$.
     152             : By including the MASK keyword in the LOCAL_AVERAGE line we reduce the number of local averages that are computed. These quantities are only calculated for those
     153             : atoms that are within the spherical region of interest.  However, we are still asking PLUMED to calculate the coordination numbers for many atoms that
     154             : will not contribute to the final averaged quantity in the COORDINATIONNUMBER commmand with label `cc`.  If you use an input like the one shown below you can ensure
     155             : that only those coordiantion numbers that compute to the final average are computed.
     156             : 
     157             : ```plumed
     158             : # Fixed virtual atom which serves as the probe volume's center (pos. in nm)
     159             : center: FIXEDATOM AT=2.5,2.5,2.5
     160             : # Vector in which element i is one if atom i is in sphere of interest and zero otherwise
     161             : sphere: INSPHERE ATOMS=1-400 CENTER=center RADIUS={GAUSSIAN D_0=0.5 R_0=0.01 D_MAX=0.52}
     162             : ones: ONES SIZE=400
     163             : # Calculate a elements of adjacency matrix for those elements that are inside the sphere
     164             : vol_cmap: CONTACT_MATRIX GROUP=1-400 SWITCH={RATIONAL D_0=1.3 R_0=0.2 D_MAX=3.0} MASK=sphere
     165             : # Create a matrix that for the sphere stuff
     166             : sphere_mat: OUTER_PRODUCT ARG=sphere,ones MASK=vol_cmap
     167             : # Multiply this contact matrix by the map
     168             : bonds_mat: CUSTOM ARG=vol_cmap,sphere_mat FUNC=x*y PERIODIC=NO
     169             : # Transpose the above matrix
     170             : bonds_matT: TRANSPOSE ARG=bonds_mat
     171             : # And multiply by the volume
     172             : bonds: MATRIX_VECTOR_PRODUCT ARG=bonds_matT,sphere
     173             : #  And make sure we calculate the coordination numbers for the atoms in the volume too
     174             : mask: CUSTOM ARG=bonds,sphere FUNC=x+y PERIODIC=NO
     175             : # Calculate the coordination number for all the atoms
     176             : cc: COORDINATIONNUMBER SPECIES=1-400 SWITCH={RATIONAL D_0=1.3 R_0=0.2 D_MAX=3.0} MASK=mask
     177             : # Calculate the local average
     178             : lcc: LOCAL_AVERAGE SPECIES=cc SWITCH={RATIONAL D_0=1.3 R_0=0.2 D_MAX=3.0} MASK=sphere
     179             : # Multiply local averages parameters numbers by sphere vector
     180             : prod: CUSTOM ARG=lcc,sphere FUNC=x*y PERIODIC=NO
     181             : # Sum of coordination numbers for atoms that are in the sphere of interest
     182             : numer: SUM ARG=prod PERIODIC=NO
     183             : # Number of atoms that are in sphere of interest
     184             : denom: SUM ARG=sphere PERIODIC=NO
     185             : # Average coordination number for atoms in sphere of interest
     186             : av: CUSTOM ARG=numer,denom FUNC=x/y PERIODIC=NO
     187             : # And print out final CV to a file
     188             : PRINT ARG=av FILE=colvar STRIDE=1
     189             : ```
     190             : 
     191             : In the above input the only elements of the [CONTACT_MATRIX](CONTACT_MATRIX.md) with label `vol_cmap` that are non-zero are those that are bonded to one of the atoms
     192             : in the sphere of interest.  By transposing this matrix and multiplying by a vector of ones we thus get a vector with a length equal to total number of coordination
     193             : numbers in the system. The only elements in this vector that are non-zero are those that are bonded to atoms that are within the sphere of interest.  Consequently,
     194             : if we add the vector `sphere` to this we can a vector in which element $i$ is only non-zero if we have to calculate that coordination number to evaluate the final
     195             : quantity of interest.
