      37             : /*
      38             : Calculate an arbitrary function of all the bond vectors in the first coordination sphere of an atom
      39             : 
      40             : This shortcut allows you to calculate the sum for an arbitrary function of the bond vectors that connect an atom to each of its neighbours.
      41             : In other words, this action allows you to compute the following:
      42             : 
      43             : $$
      44             : s_i = \sum_{i \ne j} \sigma(r_{ij}) f(x_{ij}, y_{ij}, z_{ij}, r_{ij}) )
      45             : $$
      46             : 
      47             : In this expression, $x_{ij}, y_{ij}, z_{ij}$ are the components of the vector connecting atoms $i$ and $j$ and $r_{ij}$ is the magnitude of this vector.
      48             : $\sigma(r_{ij})$ is then a switching function that ensures that the aritrary function $f$ is only evaluated for if atom $j$ is within a certain cutoff distance
      49             : of atom $i$.
      50             : 
      51             : Below you can see a simple example that shows how this action can be used in practise.
      52             : 
      53             : ```plumed
      54             : cv: COORDINATION_SHELL_FUNCTION SPECIES=1-64 D_0=3.0 R_0=1.5 FUNCTION=((x+y+z)/r)^3+((x-y-z)/r)^3+((-x+y-z)/r)^3+((-x-y+z)/r)^3
      55             : PRINT ARG=cv FILE=colvar
      56             : ```
      57             : 
      58             : The above input calculates 64 $s_i$ values - one $s_i$ values for each of the atoms specified using the SPECIES keyword.  These 64 numbers are then output to a file.
      59             : The function of x, y, z and r to be evaluated is specified using the FUNCTION keyword.  Obviously, if your function does not depend on all four of these variables
      60             : they can be excluded from your function.
      61             : 
      62             : In the input above we use a rational [switching function](LESS_THAN.md) with the parameters above. We would recommend using SWITCH syntax
      63             : rather than the syntax above when giving the parameters for the switching function as you can then use any of the switching functions described
      64             : in the documentation for [LESS_THAN](LESS_THAN.md).  More importantly, however, using this syntax allows you to set the D_MAX parameter for the
      65             : switching function as demonstrated below:
      66             : 
      67             : ```plumed
      68             : cv: COORDINATION_SHELL_FUNCTION ...
      69             :    SPECIES=1-64 SWITCH={RATIONAL D_0=3.0 R_0=1.5 D_MAX=7.0}
      70             :    FUNCTION=((x+y+z)/r)^3+((x-y-z)/r)^3+((-x+y-z)/r)^3+((-x-y+z)/r)^3
      71             : ...
      72             : PRINT ARG=cv FILE=colvar
      73             : ```
      74             : 
      75             : Setting the `D_MAX` can substantially improve PLUMED performance as it turns on the linked list algorithm that is discussed in the optimisation details part
      76             : of the documentation for [CONTACT_MATRIX](CONTACT_MATRIX.md).
      77             : 
      78             : ## Rotating the reference frame
      79             : 
      80             : As discussed in [this paper](https://journals.aps.org/prb/abstract/10.1103/PhysRevB.92.180102) it is sometimes useful to rotate the bond vectors before computing the
      81             : arbitrary function $f$ in the above expression.  To perform such rotations you use the PHI, THETA and PSI keywords.  The $x_{ij}, y_{ij}$ and $z_{ij}$ values that enter $f$ in the
      82             : expression above are then calculated as:
      83             : 
      84             : $$
      85             : \left(
      86             : \begin{matrix}
      87             : x_{ij} \\
      88             : y_{ij} \\
      89             : z_{ij}
      90             : \end{matrix}
      91             : \right) =
      92             : \left(
      93             : \begin{matrix}
      94             : \cos(\psi)\cos(\phi) - \cos(\theta)\sin(\phi)\sin(\psi) & \cos(\psi)*\sin(\phi)+\cos(\theta)*\cos(\phi)*\sin(\psi) & \sin(\psi)*sin(\theta) \\
      95             : -\sin(\psi)*\cos(\phi)-\cos(\theta)*\sin(\phi)*\cos(\psi) & -\sin(\psi)*\sin(\phi)+\cos(\theta)*\cos(\phi)*std::cos(\psi), & \cos(\psi)*\sin(\theta) \\
      96             : \sin(\theta)*\sin(\phi) & \sin(\theta)*\cos(\phi) & \cos(\theta)
      97             : \end{matrix}
      98             : \right)
      99             : \left(
     100             : \begin{matrix}
     101             : x_{ij}' \\
     102             : y_{ij}' \\
     103             : z_{ij}'
     104             : \end{matrix}
     105             : \right)
     106             : $$
     107             : 
     108             : $x_{ij}', y_{ij}'$ and $z_{ij}'$ in this expression are the bond vectors that are calculated in the lab frame.  The matrix in the above expression is thus just a
     109             : [rotation matrix](https://en.wikipedia.org/wiki/Rotation_matrix) that converts the lab frame to some frame of interest.
     110             :

     272             : the following quantity:

     369             : //+PLUMEDOC MCOLVAR TETRAHEDRAL
     370             : /*
     371             : Calculate the degree to which the environment about ions has a tetrahedral order.
     372             : 
     373             : This shortcut is an example of a [COORDINATION_SHELL_AVERAGE](COORDINATION_SHELL_AVERAGE.md),
     374             : which we can use to measure the degree to which the atoms in the first coordination shell around any atom, $i$ is
     375             : is arranged like a tetrahedron.  We perform this comparison by evaluating the following function.
     376             : 
     377             : $$
     378             :  s(i) = \frac{1}{\sum_j \sigma( r_{ij} )} \sum_j \sigma( r_{ij} )\left[ \frac{(x_{ij} + y_{ij} + z_{ij})^3}{r_{ij}^3} +
     379             :                                                                         \frac{(x_{ij} - y_{ij} - z_{ij})^3}{r_{ij}^3} +
     380             :                                                                         \frac{(-x_{ij} + y_{ij} - z_{ij})^3}{r_{ij}^3} +
     381             :                                                                         \frac{(-x_{ij} - y_{ij} + z_{ij})^3}{r_{ij}^3} \right]
     382             : $$
     383             : 
     384             : Here $r_{ij}$ is the magnitude of the vector connecting atom $i$ to atom $j$ and $x_{ij}$, $y_{ij}$ and $z_{ij}$
     385             : are its three components.  The function  $\sigma( r_{ij} )$ is a switching function that acts on the distance between
     386             : atoms $i$ and $j$.  The parameters of this function should be set so that the function is equal to one
     387             : when atom $j$ is in the first coordination sphere of atom $i$ and is zero otherwise.
     388             : 
     389             : The following command calculates the average value of the TETRAHEDRAL parameter for a set of 64 atoms all of the same type
     390             : and outputs this quantity to a file called colvar.
     391             : 
     392             : ```plumed
     393             : tt: TETRAHEDRAL SPECIES=1-64 D_0=3.0 R_0=1.5 NN=6 MM=12
     394             : tt_mean: MEAN ARG=tt PERIODIC=NO

     424             : ## The MASK keyword
     425             : 
     426             : You can use the MASK keyword with this action in the same way that it is used with [COORDINATIONNUMBER](COORDINATIONNUMBER.md).  This keyword thus expects a vector in
     427             : input, which tells TETRAHEDRAL that it is safe not to calculate the TETRAHEDRAL parameter for some of the atoms.  As illustrated below, this is useful if you are using functionality
     428             : from the [volumes module](module_volumes.md) to calculate the average value of the TETRAHEDRAL parameter for only those atoms that lie in a certain part of the simulation box.
     429             : 
     430             : ```plumed
     431             : # Fixed virtual atom which serves as the probe volume's center (pos. in nm)
     432             : center: FIXEDATOM AT=2.5,2.5,2.5
     433             : # Vector in which element i is one if atom i is in sphere of interest and zero otherwise
     434             : sphere: INSPHERE ATOMS=1-400 CENTER=center RADIUS={GAUSSIAN D_0=0.5 R_0=0.01 D_MAX=0.52}
     435             : # Calculate the tetrahedral parameter of the atoms
     436             : cc: TETRAHEDRAL ...
     437             :   SPECIES=1-400 MASK=sphere
     438             :   SWITCH={RATIONAL D_0=3.0 R_0=1.5 D_MAX=6.0}
     439             : ...
     440             : # Multiply fccubic parameters numbers by sphere vector
     441             : prod: CUSTOM ARG=cc,sphere FUNC=x*y PERIODIC=NO
     442             : # Sum of coordination numbers for atoms that are in the sphere of interest
     443             : numer: SUM ARG=prod PERIODIC=NO
     444             : # Number of atoms that are in sphere of interest
     445             : denom: SUM ARG=sphere PERIODIC=NO
     446             : # Average coordination number for atoms in sphere of interest
     447             : av: CUSTOM ARG=numer,denom FUNC=x/y PERIODIC=NO
     448             : # And print out final CV to a file
     449             : PRINT ARG=av FILE=colvar STRIDE=1
     450             : ```
     451             : 
     452             : This input calculate the average value of the TETRAHEDRAL parameter for only those atoms that are within a spherical region that is centered on the point
     453             : $(2.5,2.5,2.5)$.
