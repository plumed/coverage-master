      36             : /*
      37             : Calculate the local crystalinity symmetry function
      38             : 
      39             : This shortcut provides an implementation of the local crystalinity order parameter that is described in the paper in the bibliography.
      40             : To use this CV you define a series of unit vectors, $g_k$, using multiple instances of the GVECTOR keyword.  This allows you to define a
      41             : [symmetry function](https://www.plumed-tutorials.org/lessons/23/001/data/SymmetryFunction.html) for the $i$th atom as:
      42             : 
      43             : $$
      44             : s_i = \sum_k \left| \frac{\sum_j \sigma(|r_{ij}|) e^{ig_k r_{ij}}}{\sum_j \sigma(|r_{ij}|)} \right|^2
      45             : $$
      46             : 
      47             : In this expression $r_{ij}$ is the vector connecting atom $i$ to atom $j$ and $\sigma$ is a switching function that acts upon the magnidue of this vector, $|r_{ij}|$.
      48             : The following input is an example that shows how this symmetry function can be used in practice.
      49             : 
      50             : ```plumed
      51             : lc: LOCAL_CRYSTALINITY ...
      52             :    SPECIES=1-64 D_0=3.0 R_0=1.5
      53             :    GVECTOR1=1,1,1 GVECTOR2=1,0.5,0.5 GVECTOR3=0.5,1.0,1.0 SUM
      54             : ...
      55             : PRINT ARG=lc_sum FILE=colvar
      56             : ```
      57             : 
      58             : As you can see if you expand the shortcut in this input, the sum over $k$ in the above expression has three terms in this input as 3 GVECTORS are specified.
      59             : Sixty four values for the expression above are computed.  These sixty four numbers are then added together in order to give a global mesuare of the crystallinity
      60             : for the simulated system.
      61             : 
      62             : In the input above $\sigma(|r_{ij}|)$ is a rational [switching function](LESS_THAN.md)
      63             : with the parameters above. We would recommend using SWITCH syntax
      64             : rather than the syntax above when giving the parameters for the switching function as you can then use any of the switching functions described
      65             : in the documentation for [LESS_THAN](LESS_THAN.md).  More importantly, however, using this syntax allows you to set the D_MAX parameter for the
      66             : switching function as demonstrated below:
      67             : 
      68             : ```plumed
      69             : lc: LOCAL_CRYSTALINITY ...
      70             :    SPECIES=1-64 SWITCH={RATIONAL D_0=3.0 R_0=1.5 D_MAX=3.0}
      71             :    GVECTOR1=1,1,1 GVECTOR2=1,0.5,0.5 GVECTOR3=0.5,1.0,1.0 SUM
      72             : ...
      73             : PRINT ARG=lc_sum FILE=colvar
      74             : ```
      75             : 
      76             : ## Working with two types of atom
      77             : 
      78             : If you would like to calculate the function above for the bonds connecting the atoms in GROUPA to the atoms in GROUPB you can use an input like the one
      79             : shown below:
      80             : 
      81             : ```plumed
      82             : lc: LOCAL_CRYSTALINITY ...
      83             :    SPECIESA=1-5 SPECIESB=1-64 SWITCH={RATIONAL D_0=3.0 R_0=1.5 D_MAX=3.0}
      84             :    GVECTOR1=1,1,1 GVECTOR2=1,0.5,0.5 GVECTOR3=0.5,1.0,1.0 SUM
      85             : ...
      86             : PRINT ARG=lc_sum FILE=colvar
      87             : ```
      88             : 
      89             : ## The MASK keyword
      90             : 
      91             : You can use the MASK keyword with this action in the same way that it is used with [COORDINATIONNUMBER](COORDINATIONNUMBER.md).  This keyword thus expects a vector in
      92             : input, which tells PLUMED the atoms for which you do not need to calculate the function.  As illustrated below, this is useful if you are using functionality
      93             : from the [volumes module](module_volumes.md) to calculate the average value of the TETRAHEDRAL parameter for only those atoms that lie in a certain part of the simulation box.
      94             : 
      95             : ```plumed
      96             : # Fixed virtual atom which serves as the probe volume's center (pos. in nm)
      97             : center: FIXEDATOM AT=2.5,2.5,2.5
      98             : # Vector in which element i is one if atom i is in sphere of interest and zero otherwise
      99             : sphere: INSPHERE ATOMS=1-64 CENTER=center RADIUS={GAUSSIAN D_0=0.5 R_0=0.01 D_MAX=0.52}
     100             : # Calculate the local crystallinity parameters
     101             : lc: LOCAL_CRYSTALINITY ...
     102             :    SPECIES=1-64 SWITCH={RATIONAL D_0=3.0 R_0=1.5 D_MAX=3.0}
     103             :    GVECTOR1=1,1,1 GVECTOR2=1,0.5,0.5 GVECTOR3=0.5,1.0,1.0 MASK=sphere
     104             : ...
     105             : # Multiply local crystallinity parameters numbers by sphere vector
     106             : prod: CUSTOM ARG=lc,sphere FUNC=x*y PERIODIC=NO
     107             : # Sum of coordination numbers for atoms that are in the sphere of interest
     108             : numer: SUM ARG=prod PERIODIC=NO
     109             : # Number of atoms that are in sphere of interest
     110             : denom: SUM ARG=sphere PERIODIC=NO
     111             : # Average coordination number for atoms in sphere of interest
     112             : av: CUSTOM ARG=numer,denom FUNC=x/y PERIODIC=NO
     113             : # And print out final CV to a file
     114             : PRINT ARG=av FILE=colvar STRIDE=1
     115             : ```
     116             : 
     117             : This input calculate the average local crystallinity parameter for only those atoms that are within a spherical region that is centered on the point
     118             : $(2.5,2.5,2.5)$.
     119             :
