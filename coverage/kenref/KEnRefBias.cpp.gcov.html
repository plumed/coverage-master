      70             : /*
      71             : Restrains an ensemble of replicas against NMR observables (kinetic ensemble refinement).
      72             : 
      73             : KENREF computes an NMR observable as an average over the whole ensemble of replicas, compares it with
      74             : experimental data, and applies the resulting restraint force to the atoms. Unlike most biases it acts on
      75             : coordinates rather than on collective variables, so it takes **no** `ARG`.
      76             : 
      77             : The energy model is selected by name with `MODEL`:
      78             : 
      79             : | `MODEL`    | restrains                                          |
      80             : |:-----------|:---------------------------------------------------|
      81             : | `SIGMA`    | cross-relaxation rates (interproton NOE build-up)  |
      82             : | `PLATEAUS` | NOE plateau values                                 |
      83             : | `RELAX`    | longitudinal / transverse relaxation               |
      84             : 
      85             : Because the observable is an ensemble average, `RELAX` needs at least two replicas (run with `--multi`);
      86             : `SIGMA` and `PLATEAUS` also work with a single replica.
      87             : 
      88             : `EXP_DATA_FOLDER` holds the experimental data and the atom-pair definitions. `ATOMNAME_MAPPING` is a PDB
      89             : that maps atom names to indices, and is also used as the reference structure when `REF` is omitted. When
      90             : `FIT_TO_REFERENCE` is set the coordinates are Kabsch-fitted onto the reference, using `GUIDE_ATOMS`,
      91             : before the observable is computed, and the derivatives are rotated back afterwards. `SATURATE_FORCES`
      92             : clamps the resulting force to `MAX_FORCE`.
      93             : 
      94             : The restraint needs whole molecules: the fit uses all `GUIDE_ATOMS` at once and the atom-pair distances
      95             : have no cutoff. At every step KENREF therefore moves each atom it reads to the periodic image nearest its
      96             : neighbour in a spanning tree built from the reference structure. The reference must be whole itself; if
      97             : one edge of that tree is not shorter than half the smallest box width, KENREF stops with an error.
      98             : Coordinates that are already whole are left unchanged.
      99             : 
     100             : The action outputs its restraint energy as `.energy` (equal to `.bias`) and, as a diagnostic, the RMSD
     101             : from the reference as `.rmsd`.
     102             : 
     103             : This module needs the external KEnRef library and is not compiled by default; see the module
     104             : documentation for how to build it.
     105             : 
     106             : ## Examples
     107             : 
     108             : Restraining a fragment of GB3 against cross-relaxation rates:
     109             : 
     110             : ```plumed
     111             : #SETTINGS MOLFILE=regtest/kenref/rt-kenref-sigma/gb3_frag.pdb
     112             : kenref: KENREF ...
     113             :   MODEL=SIGMA
     114             :   K=1.0
     115             :   N=0.25
     116             :   PROTON_MHZ=700.0
     117             :   EXP_DATA_FOLDER=regtest/kenref/rt-kenref-sigma/
     118             :   REF=regtest/kenref/rt-kenref-sigma/gb3_frag.pdb
