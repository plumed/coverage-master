      30             : /*
      31             : Probe the parallel beta sheet content of your protein structure.
      32             : 
      33             : Two protein segments containing three contiguous residues can form a parallel beta sheet.
      34             : Although if the two segments are part of the same protein chain they must be separated by
      35             : a minimum of three residues to make room for the turn. This colvar thus generates the set of
      36             : all possible six residue sections (residues $i$, $i+1$, $i+2$ and $j$, $j+1$, $j+2$) that could conceivably form a parallel beta sheet
      37             : and calculates the [DRMSD](DRMSD.md) or [RMSD](RMSD.md) distance between the configuration in which the residues find themselves
      38             : and an idealized parallel beta sheet structure. These distances can be calculated by either
      39             : aligning the instantaneous structure with the reference structure and measuring each
      40             : atomic displacement or by calculating differences between the set of inter-atomic
      41             : distances in the reference and instantaneous structures. The backbone atoms N, CA, CB, C and O
      42             : of each residue are used (for glycine the HA2 atom is used in place of CB), so each section contains 30 atoms.
      43             : 
      44             : Two reference structures are used for the parallel beta sheet, and for each segment the distance is the lowest of the
      45             : two distances (the vector `label_low` in the expanded input). The vectors of the distances from the two references are the
      46             : components `struct-1` and `struct-2` of the action labelled `label_both` in the expanded input.
      47             : 
      48             : This colvar is based on the paper cited below.  The authors of
      49             : this paper use the set of distances from the parallel beta sheet configurations to measure
      50             : the number of segments whose configuration resembles a parallel beta sheet. This is done by calculating
      51             : the following sum of functions of the rmsd distances:
      52             : 
      53             : $$
      54             : s = \sum_i \frac{ 1 - \left(\frac{r_i-d_0}{r_0}\right)^n } { 1 - \left(\frac{r_i-d_0}{r_0}\right)^m }
      55             : $$
      56             : 
      57             : where the sum runs over all possible segments of parallel beta sheet.  By default the
      58             : NN, MM, D_0 and R_0 parameters are set equal to those used in the paper cited below, which are
      59             : $n=8$, $m=12$, $d_0=0$ and $r_0=0.08$ nm. The value of R_0 is given in the length units of [UNITS](UNITS.md);
      60             : the default is converted, so it is always 0.08 nm. As in the other actions that take R_0, NN, MM and D_0, the function above, $f(r)$,
      61             : is stretched so that it goes to zero at $d_{max}=d_0+r_0\,10^{5/(m-n)}$, where $f(d_{max})=10^{-5}$ (1.42 nm with the default
      62             : parameters): each segment contributes $\left(f(r_i)-f(d_{max})\right)/\left(1-f(d_{max})\right)$ if $r_i<d_{max}$ and zero otherwise.
      63             : The value of $d_{max}$ is the D_MAX of the switching function in the expanded input. The segments with a distance from the
      64             : reference larger than $d_{max}$, whose strands are far apart, are then not computed (see below).
      65             : To use the function without stretching, use LESS_THAN={RATIONAL R_0=0.08 NN=8 MM=12}.
      66             : 
      67             : If you would like to use a different switching function you can use the LESS_THAN keyword, as in the second example below,
      68             : where D_MAX is given as for the default function, so that the pairs of strands that are too far apart can be skipped also with this function.
      69             : In this case the label of the action is the vector of the distances between each segment and the ideal parallel beta sheet, and
      70             : the number of segments that are similar to a parallel beta sheet is the `lessthan` component.
      71             : 
      72             : The following input calculates the number of six residue segments of
      73             : protein that are in a parallel beta sheet configuration.
      74             : 
      75             : ```plumed
      76             : #SETTINGS MOLFILE=regtest/basic/rt32/helix.pdb
      77             : MOLINFO STRUCTURE=regtest/basic/rt32/helix.pdb
      78             : pb: PARABETARMSD RESIDUES=all R_0=0.1
      79             : PRINT ARG=pb FILE=colvar
      80             : ```
      81             : 
      82             : Here the same is done using [RMSD](RMSD.md) instead of [DRMSD](DRMSD.md), and with the LESS_THAN keyword. The cost of the two methods is similar.
      83             : 
      84             : ```plumed
      85             : #SETTINGS MOLFILE=regtest/basic/rt32/helix.pdb
      86             : MOLINFO STRUCTURE=regtest/basic/rt32/helix.pdb
      87             : hh: PARABETARMSD RESIDUES=all TYPE=OPTIMAL LESS_THAN={RATIONAL R_0=0.1 NN=8 MM=12 D_MAX=1.78}
      88             : PRINT ARG=hh.lessthan FILE=colvar
      89             : ```
      90             : 
      91             : ## Strands cutoff
      92             : 
      93             : The segments that have the two strands of the beta sheet further apart than `STRANDS_CUTOFF` are not computed, and they contribute
      94             : zero to the number of segments that are similar to a beta sheet. The distance between the two strands is the distance between the
      95             : CA atoms of their central residues. The default cutoff is 1 nm (the cutoff is in the length units of [UNITS](UNITS.md), the default
      96             : is converted). This makes the calculation much faster, as the number of pairs of strands grows with the square of the number of residues.
      97             : Use `STRANDS_CUTOFF=0` to compute all the pairs: the number of segments then also includes the small contributions of the many segments
      98             : whose strands are far apart (with 18 peptides of 8 residues about 1 more segment). If you use LESS_THAN together with STRANDS_CUTOFF,
      99             : notice that the distances of the skipped segments are zero in the vector that is the value of the action, so this vector
     100             : should not be used to find the segment that is closest to a beta sheet.
     101             : 
     102             : ## How the number of segments is computed
     103             : 
     104             : Without `USEGPU`, the number of segments that are similar to a sheet (the value of the action, or its `lessthan` component when
     105             : LESS_THAN is used) is computed by a single action, PARABETARMSD_SCALAR, which loops over the pairs of strands, skips those that are further
     106             : apart than `STRANDS_CUTOFF` and adds the derivatives of each segment directly to the atoms. When the switching function goes to zero at
     107             : a finite distance (as the default one, or with D_MAX in LESS_THAN), it also skips the pairs of strands that are so far apart that the
     108             : distance of the segment from the reference is certainly larger than that distance (this does not change the result, and makes
     109             : STRANDS_CUTOFF=0 cheaper). The vectors that appear in the expanded input
     110             : (the distances of the strands, the distances from the reference structure and their switching functions) are only computed when they are
     111             : used elsewhere in the input, e.g. when the vector that is the value of the action with LESS_THAN is printed. The result is the same.
     112             : With `USEGPU` and TYPE=DRMSD the same calculation is done on the GPU by PARABETARMSD_SCALAR_ACC, from the openaccPTM plugin: one GPU thread per pair of strands within `STRANDS_CUTOFF`. With `USEGPU` and the other types the number of segments is the sum of the vector of the switching functions.
     113             : 
     114             : ## Chains and residues
     115             : 
     116             : The STYLE keyword selects whether the two strands of a segment are taken from the same chain (STYLE=intra), from different
     117             : chains (STYLE=inter) or both (STYLE=all, the default). With STYLE=intra and STYLE=all each chain must contain at least 8 residues,
     118             : otherwise PLUMED stops with an error; for systems made of short peptides (for example in studies of aggregation) use STYLE=inter.
     119             : 
     120             : ## Periodic boundary conditions
     121             : 
     122             : Unless the NOPBC flag is used, each six residue section is made whole before computing its distance from the reference.
     123             : The two strands of three residues are made whole separately: the atoms N, CA, CB, C and O of each strand are taken in this order,
     124             : and each atom is moved to the periodic image that is closest to the previous one, as is done by [WHOLEMOLECULES](WHOLEMOLECULES.md).
     125             : The second strand is then moved to the periodic image where the CA atom of its central residue is closest to the CA atom of the
     126             : central residue of the first strand (this is the ALIGN_STRANDS flag of [SECONDARY_STRUCTURE_RMSD](SECONDARY_STRUCTURE_RMSD.md)).
     127             : This is done in the same way for [DRMSD](DRMSD.md) and [RMSD](RMSD.md), so there is no need to use [WHOLEMOLECULES](WHOLEMOLECULES.md)
     128             : before this action. The distance used with STRANDS_CUTOFF is also computed with the periodic boundary conditions.
     129             : You can turn off this treatment by using the NOPBC flag as shown below:
     130             : 
     131             : ```plumed
     132             : #SETTINGS MOLFILE=regtest/basic/rt32/helix.pdb
     133             : MOLINFO STRUCTURE=regtest/basic/rt32/helix.pdb
     134             : pb: PARABETARMSD RESIDUES=all R_0=0.1 NOPBC
     135             : PRINT ARG=pb FILE=colvar
     136             : ```
     137             : 
     138             : */
