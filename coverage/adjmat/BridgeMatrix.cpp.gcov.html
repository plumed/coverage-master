      29             : /*
      30             : Calculate the number of atoms that bridge two parts of a structure
      31             : 
      32             : This adjacency matrix is used to implement the [BRIDGE](BRIDGE.md) shortcut. The action outputs a adjacency matrix
      33             : in the same way as [CONTACT_MATRIX](CONTACT_MATRIX.md).  However, the  $j,k$ element of the adjacency matrix is calculated
      34             : using:
      35             : 
      36             : $$
      37             : M_{jk} = \sum_i s_A(r_{ij})s_B(r_{ik})
      38             : $$
      39             : 
      40             : In this expression, the sum runs over all the atoms that were specified using the `BRIDGING_ATOMS` keyword, $s_A$ and
      41             : $s_B$ are switching functions, and $r_{ij}$ and $r_{ik}$ are the distances between atom $i$ and $j$ and between atoms
      42             : $i$ and $k$.  Less formally, this formula ensures that $j,k$ element of the output matrix is one if there is a bridging
      43             : atom between atom $j$ and $k$.
      44             : 
      45             : Notice that the BRIDGE_MATRIX action is also a shortcut. If we have a single group of non-bridging atoms then we can compute
      46             : the contact matrix $\mathbf{C}$ between the non-bridging and bridging atoms. The BRIDGE_MATRIX, $\mathbf{M}$, can by calculated
      47             : from $\mathbf{C}$ by multiplying $\mathbf{C}$ by its transpose.  Similarly, if we have two groups of non-bridging atoms
      48             : we can calculate the BRIDGE_MATRIX by calculating a [CONTACT_MATRIX](CONTACT_MATRIX.md) between the first set of non-bridging atoms and
      49             : a second [CONTACT_MATRIX](CONTACT_MATRIX.md) between the bridging atoms and the bridging atoms and the second set of non-bridging atoms.
      50             : The bridge matrix is the product of these two matrices.
      51             : 
      52             : In the following example input atoms 100-200 can serve as bridging atoms between the atoms in GROUPA and GROUPB and the
      53             : two switching functions $s_A$ and $s_B$ in the formula above are identical.
      54             : 
      55             : ```plumed
      56             : w1: BRIDGE_MATRIX ...
      57             :    BRIDGING_ATOMS=100-200
      58             :    GROUPA=1-10 GROUPB=11-20
      59             :    SWITCH={RATIONAL R_0=0.2}
      60             : ...
      61             : ```
      62             : 
      63             : If you use a single GROUP keyword as in the input below as a single SWITCH keyword the output matrix is symmetric.
      64             : 
      65             : ```plumed
      66             : w2: BRIDGE_MATRIX ...
      67             :    BRIDGING_ATOMS=100-200 GROUP=1-10
      68             :    SWITCH={RATIONAL R_0=0.2}
      69             : ...
      70             : ```
      71             : 
      72             : However, if the two switching functions are not identical, as in the following example, then the output matrix is __not__ symmetric
      73             : even if GROUP is used rather than GROUPA/GROUPB.
      74             : 
      75             : ```plumed
      76             : w2: BRIDGE_MATRIX ...
      77             :    BRIDGING_ATOMS=100-200 GROUP=1-10
      78             :    SWITCHA={RATIONAL R_0=0.2}
      79             :    SWITCHB={RATIONAL R_0=0.4}
      80             : ...
      81             : ```
      82             : 
      83             : Notice that in all the inputs above the $r_{ij}$ and $r_{ik}$ values that enter the formula above are calculated in a way that takes the
      84             : periodic boundary conditions into account.  If you want to ignore the periodic boundary conditions you can use the NOPBC flag as shown below.
      85             : 
      86             : ```plumed

      88             :    BRIDGING_ATOMS=100-200 GROUP=1-10
      89             :    SWITCH={RATIONAL R_0=0.2}
      90             :    NOPBC

      92             : ```
