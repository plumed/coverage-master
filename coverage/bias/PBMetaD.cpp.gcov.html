      42             : /*
      43             : Used to performed Parallel Bias metadynamics.
      44             : 
      45             : This action provides an implementation of the Parallel Bias Metadynamics (PBMetaD) method that was introduced in the first paper cited below.
      46             : This variant of metadynamics (see [METAD](METAD.md)) uses multiple low-dimensional bias potentials that are applied in parallel.
      47             : In the current implementation, these have the form of mono-dimensional metadynamics bias
      48             : potentials:
      49             : 
      50             : $$
      51             : {V(s_1,t), ..., V(s_N,t)}
      52             : $$
      53             : 
      54             : where:
      55             : 
      56             : $$
      57             : V(s_i,t) = \sum_{ k \tau < t} W_i(k \tau)
      58             : \exp\left(
      59             : - \frac{(s_i-s_i^{(0)}(k \tau))^2}{2\sigma_i^2}
      60             : \right).
      61             : $$
      62             : 
      63             : To ensure the convergence of each mono-dimensional bias potential to the corresponding free energy,
      64             : at each deposition step the Gaussian heights are multiplied by the so-called conditional term:
      65             : 
      66             : $$
      67             : W_i(k \tau)=W_0 \frac{\exp\left(
      68             : - \frac{V(s_i,k \tau)}{k_B T}
      69             : \right)}{\sum_{i=1}^N
      70             : \exp\left(
      71             : - \frac{V(s_i,k \tau)}{k_B T}
      72             : \right)}
      73             : $$
      74             : 
      75             : where $W_0$ is the initial Gaussian height.
      76             : 
      77             : The PBMetaD bias potential is defined by:
      78             : 
      79             : $$
      80             : V_{PB}(\vec{s},t) = -k_B T \log{\frac{1}{N}\sum_{i=1}^N
      81             : \exp\left(
      82             : - \frac{V(s_i,t)}{k_B T}
      83             : \right)}.
      84             : $$
      85             : 
      86             : PBMETAD needs the temperature: give it with TEMP, unless the MD engine passes it to PLUMED.
      87             : As in [METAD](METAD.md), the Gaussians are truncated and stretched so that they go to zero at the cutoff
      88             : (the hills files contain stretched Gaussians, which is what [sum_hills](sum_hills.md) assumes).
      89             : 
      90             : 
      91             : Information on the Gaussian functions that build each bias potential are printed to
      92             : multiple HILLS files, which
      93             : are used both to restart the calculation and to reconstruct the mono-dimensional
      94             : free energies as a function of the corresponding CVs.
      95             : These can be reconstructed using the [sum_hills](sum_hills.md) utility because the final bias is given
      96             : by:
      97             : 
      98             : $$
      99             : V(s_i) = -F(s_i)
     100             : $$
     101             : 
     102             : Currently, only a subset of the [METAD](METAD.md) options are available in PBMetaD.
     103             : 
     104             : The bias potentials can be stored on a grid to increase performances of long PBMetaD simulations.
     105             : You should
     106             : provide either the number of bins for every collective variable (GRID_BIN) or
     107             : the desired grid spacing (GRID_SPACING). In case you provide both PLUMED will use
     108             : the most conservative choice (highest number of bins) for each dimension.
     109             : In case you do not provide any information about bin size (neither GRID_BIN nor GRID_SPACING)
     110             : and if Gaussian width is fixed PLUMED will use 1/5 of the Gaussian width as grid spacing.
     111             : This default choice should be reasonable for most applications.
     112             : 
     113             : As in [METAD](METAD.md), the grids are extended automatically, along the variables that are not periodic, whenever a
     114             : Gaussian does not fit in them: a grid always contains all the points where a Gaussian is not zero, so that the bias is
     115             : exactly zero outside it (with INTERVAL_MIN and INTERVAL_MAX, the grid contains the interval, and beyond the limits the bias
     116             : is the constant value at the limits).  The grid spacing does not change and the new points are on the same lattice as the initial ones.
     117             : Every extension is written on the log.  If you give GRID_SPACING without GRID_MIN and GRID_MAX each grid is placed
     118             : around its first Gaussian and then extended as needed.  GRID_SIZE_LIMIT sets the maximum number of points of each grid.
     119             : A grid read with GRID_RFILES can have any range, but it must be on the lattice of the grid given in input.
     120             : 
     121             : As in [METAD](METAD.md), no Gaussian is added at the first step of a simulation.  When a simulation is continued with
     122             : RESTART and the bias is read from the hills files, a Gaussian is added at the first step unless they already contain
     123             : it (i.e. the previous run had already performed this step).  When the bias is read from the grids (GRID_RFILES), the hills files are still read,
     124             : without adding their hills to the bias, to know the time of their last hill.  With WALKERS_N, the grids written by a walker
     125             : contain also the hills it has read from the files of the other walkers (their number is written in a comment line after
     126             : the grid), and only the hills of the other walkers that are not in the grids are added.
     127             : 
     128             : With ADAPTIVE=DIFF, as in [METAD](METAD.md), when restarting the statistics of the fluctuations of each variable
     129             : (running average and variance) are initialized from its last hills in the hills file of its family, so that the hills
     130             : deposited after the restart have the same width they would have had without the restart (use DIFF_FROM_SCRATCH to
     131             : accumulate the statistics from scratch).  With replica exchange, the running averages of the variables are
     132             : restarted when an exchange is accepted, and the variances are kept.
     133             : With PRECAL_DIFF the statistics are accumulated at every step, also outside the update window (UPDATE_FROM,
     134             : UPDATE_UNTIL), so that the first hills have a width estimated over a sufficiently long time.
     135             : 
     136             : With GRID_WSTRIDE the grids are written to the GRID_WFILES, overwriting the previous ones, or, with STORE_GRIDS,
     137             : appending them one after the other.
     138             : 
     139             : Another option that is available is the well-tempered metadynamics that is discussed in the second paper cited below. In this
     140             : variant of PBMetaD the heights of the Gaussian hills are scaled at each step by the
     141             : additional well-tempered metadynamics term.
     142             : This  ensures that each bias converges more smoothly. It should be noted that, in the case of well-tempered metadynamics, in
     143             : the output printed the Gaussian height is re-scaled using the bias factor.
     144             : Also notice that with well-tempered metadynamics the HILLS files do not contain the bias,
     145             : but the negative of the free-energy estimate. This choice has the advantage that
     146             : one can restart a simulation using a different value for the $\Delta T$. The applied bias will be scaled accordingly.
     147             : As in [METAD](METAD.md), BIASFACTOR can also be set equal to 1: in this case no bias is applied, and the hills files and
     148             : the grids contain the estimate of the negative of the free energy (the heights of the hills are those of the limit
     149             : of well-tempered metadynamics for a bias factor going to 1).  Instead of HEIGHT, one can give TAU.
     150             : 
     151             : Note that you can also use here the flexible Gaussian approach that is discussed in the third paper cited below.
     152             : This method allows you to adapt the Gaussian to the extent of Cartesian space covered by a variable or
     153             : to the space in collective variable covered in a given time. In this case the width of the deposited
     154             : Gaussian potential is denoted by one value only that is a Cartesian space (ADAPTIVE=GEOM) or a time
     155             : (ADAPTIVE=DIFF), and SIGMA_MIN and SIGMA_MAX (one value for each family) limit the widths. Note that a specific
     156             : integration technique for the deposited Gaussian kernels should be used in this case. Check the documentation for utility
     157             : sum_hills.
     158             : 
     159             : With the keywords INTERVAL_MIN and INTERVAL_MAX (one value for each family; the values for periodic variables are
     160             : ignored) one changes the metadynamics algorithm and sets the bias force equal to zero
     161             : outside the boundaries as discussed in the fourth paper cited below. If, for example, metadynamics is performed on a CV s and one is interested only
     162             : to the free energy for s > boundary, the history dependent potential is still updated according to the above
     163             : equations but the metadynamics force is set to zero for s < boundary. Notice that Gaussian kernels are added also
     164             : if s < boundary, as the tails of these Gaussian kernels influence VG in the relevant region s > boundary. In this way, the
     165             : force on the system in the region s > boundary comes from both metadynamics and the force field, in the region
     166             : s < boundary only from the latter. This approach allows obtaining a history-dependent bias potential VG that
     167             : fluctuates around a stable estimator, equal to the negative of the free energy far enough from the
     168             : boundaries. Note that:
     169             : 
     170             : - It works only for one-dimensional biases;
     171             : - It works both with and without GRID;
     172             : - The interval limit boundary should be set in a region where the free energy derivative is not large;
     173             : - If in the region outside the limit boundary the system has a free energy minimum, INTERVAL_MIN and INTERVAL_MAX should
     174             :   be used together with a [UPPER_WALLS](UPPER_WALLS.md) or [LOWER_WALLS](LOWER_WALLS.md) at boundary.
     175             : 
     176             : For systems with multiple CVs that share identical properties, PBMetaD with partitioned families can be used
     177             : to group them under one bias potential, to which each of them contributes, as discussed in the penultimate paper in the
     178             : references below. This is done with a list of numbered PF keywords (PF0, PF1, ...), each of which contains the list of
     179             : CVs from ARG to be placed in that family. Once invoked, each CV in ARG must be placed in exactly one PF, even if it
     180             : results in families containing only one CV, and the CVs in a family must have the same periodicity.
     181             : Keywords that take one value for each argument without families (SIGMA, SIGMA_MIN, SIGMA_MAX, FILE, the GRID keywords,
     182             : INTERVAL_MIN, INTERVAL_MAX) take one value for each family instead.  The hills of all the CVs of a family are written in
     183             : the hills file of the family, as hills of its first CV.
     184             : 
     185             : With SELECTOR, the bias is applied and the hills are added only when the value of the selector (see
     186             : [SELECTOR](SELECTOR.md)) is equal to SELECTOR_ID.
     187             : 
     188             : The multiple walkers that is discussed in the final paper cited below can also be used. See below the examples.
