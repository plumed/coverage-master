      32             : //+PLUMEDOC BIAS ABMD
      33             : /*
      34             : Adds a ratchet-and-pawl like restraint on one or more variables.
      35             : 
      36             : This action can be used to evolve a system towards a target value in
      37             : CV space using an harmonic potential that moves with the thermal fluctuations of the CV.
      38             : This method was introduced in the papers cited below.  In it the biasing potential in this
      39             : method is as follows:
      40             : 
      41             : $$
      42             : V(\rho(t)) = \left \{ \begin{array}{ll} \frac{K}{2}\left(\rho(t)-\rho_m(t)\right)^2, &\rho(t)>\rho_m(t)\\
      43             :               0, & \rho(t)\le\rho_m(t), \end{array} \right .
      44             : $$
      45             : 
      46             : where
      47             : 
      48             : $$
      49             : \rho(t)=\left(CV(t)-TO\right)^2
      50             : $$
      51             : 
      52             : and
      53             : 
      54             : $$
      55             : \rho_m(t)=\min_{0\le\tau\le t}\rho(\tau)+\eta(t)
      56             : $$.
      57             : 
      58             : The method is based on the introduction of a biasing potential which is zero when
      59             : the system is moving towards the desired arrival point and which damps the
      60             : fluctuations when the system attempts to move in the opposite direction. As in the
      61             : case of the ratchet and pawl system, propelled by thermal motion of the solvent
      62             : molecules, the biasing potential does not exert work on the system. $\eta(t)$ is
      63             : an additional white noise acting on the minimum position of the bias.
      64             : 
      65             : ## The LINEAR flag
      66             : 
      67             : In the potential above the distance from the target enters through the squared distance $\rho$:
      68             : $\rho-\rho_m=(d-d_m)(d+d_m)$, with $d=|CV-TO|$ and $d_m$ the smallest distance reached, so that the effective stiffness
      69             : of the ratchet depends on how far the system is from the target (the bias is strong far from the target and
      70             : becomes quartic, hence very soft, close to it) and $K$ has the units of an energy divided by the fourth power of the CV.
      71             : With the flag `LINEAR` the ratchet is applied to the distance itself:
      72             : 
      73             : $$
      74             : V(d(t)) = \left \{ \begin{array}{ll} \frac{K}{2}\left(d(t)-d_m(t)\right)^2, &d(t)>d_m(t)\\
      75             :               0, & d(t)\le d_m(t), \end{array} \right .
      76             : \qquad
      77             : d(t)=|CV(t)-TO|,\quad d_m(t)=\min_{0\le\tau\le t}d(\tau)+\eta(t)
      78             : $$
      79             : 
      80             : In this way the target only fixes the direction in which the pawl lets the system move: the bias is a harmonic
      81             : restraint on the fluctuations of the CV away from the closest point reached so far, with the same stiffness at any distance
      82             : from the target, and $K$ has the units of an energy divided by the square of the CV (the values used with and without `LINEAR` are not interchangeable).
      83             : Note that with `LINEAR` the quantities `MIN`, `NOISE` and the components `_min` are distances (in the units of the CV) and not squared distances.
      84             : 
      85             : ## Examples
      86             : 
      87             : The following input sets up two biases, one on the distance between atoms 3 and 5
      88             : and another on the distance between atoms 2 and 4. The two target values are defined
      89             : using TO and the two strength using KAPPA. The total energy of the bias is printed.
      90             : 
      91             : ```plumed
      92             : DISTANCE ATOMS=3,5 LABEL=d1
      93             : DISTANCE ATOMS=2,4 LABEL=d2
      94             : ABMD ARG=d1,d2 TO=1.0,1.5 KAPPA=5.0,5.0 LABEL=abmd
      95             : PRINT ARG=abmd.bias,abmd.d1_min,abmd.d2_min
      96             : ```
      97             : 
      98             : The same ratchet, applied to the distances and not to the squared distances, is obtained with the flag `LINEAR`:
      99             : 
     100             : ```plumed
     101             : DISTANCE ATOMS=3,5 LABEL=d1
     102             : DISTANCE ATOMS=2,4 LABEL=d2
     103             : ABMD ARG=d1,d2 TO=1.0,1.5 KAPPA=5.0,5.0 LINEAR LABEL=abmd
     104             : PRINT ARG=abmd.bias,abmd.d1_min,abmd.d2_min
     105             : ```
     106             : 
     107             : ## Restart
     108             : 
     109             : With [CHECKPOINT](CHECKPOINT.md) the running minimum, the noise intensity and the random number generators are stored in the checkpoint, so that the restart is exact.
     110             : The checkpoint also records whether `LINEAR` was used, since the running minimum is a squared distance without it and a distance with it:
     111             : restarting from a checkpoint written with a different setting of `LINEAR` is an error.
     112             : With [RESTART](RESTART.md) and no checkpoint the running minimum is not restored: it starts again from `MIN`, or from the value of the argument at the first step.
     113             : To continue a run with the same minimum, give the last value of the `_min` components with `MIN`, or use [CHECKPOINT](CHECKPOINT.md).
     114             : 
     115             : */
