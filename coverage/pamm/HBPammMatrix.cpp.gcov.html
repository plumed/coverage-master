      32             : Adjacency matrix in which two electronegative atoms are adjacent if they are hydrogen bonded
      33             : 
      34             : This method allows you to calculate an adjacency matrix and use all the methods discussed in the documentation for
      35             : the [CONTACT_MATRIX](CONTACT_MATRIX.md) upon it to define CVs.  The $i,j$ element of the matrix that is calculated
      36             : by this action is one if there is a hydrogen bond connecting atom $i$ to atom $j$.  Furthermore, we determine whether

      38             : bibliography below and in the documentation for the [PAMM](PAMM.md) action.

      44             : m: HBPAMM_MATRIX ...

     279             : ## Optimisation details
     280             : 
     281             : If you expand the inputs above you will see that they all the [HBPAMM_MATRIX](HBPAMM_MATRIX.md) action.  The matrix that this action computes is sparse
     282             : as each atom only forms hydroen bonds with a relatively small number of neighbors.  The vast majority of the elements in the [HBPAMM_MATRIX](HBPAMM_MATRIX.md)
     283             : are thsu zero.  To reduce the amount of memory that PLUMED requires PLUMED uses sparse matrix storage.  Consequently, whenever you calculate and store a contact
     284             : matrix only the elements of the matrix that are non-zero are stored.
     285             : 
     286             : We also use the sparsity of the [HBPAMM_MATRIX](HBPAMM_MATRIX.md) to make the time required to compute the matrix scale linearly rather than quadratically with
     287             : the number of atoms. We know that element $i,j$ is only non-zero if the donor and acceptor atoms are within:
     288             : 
     289             : $$
     290             : r_c = \textrm{max}_i \left( \mu_i^{(ad)} + \sqrt(2 g_{cut}) | \sqrt{\lambda_{i,max}} v_\textrm{i,max}^{(ad)} | \right)
     291             : $$
     292             : 
     293             : where $i$ runs over all the PAMM kernels.  $g_{cut}$ is the gaussian cutoff that is specified using the REGULARIZE
     294             : keyword,  $\mu_i^{(ad)}$ is the mean acceptor-donor distance for the $i$th kernel, $\lambda_{i,max}$ is the largest
     295             : eigenvalue of the covariance for the $i$th kernel and $v_\textrm{i,max}^{(ad)}$ is the acceptor-donor distance component
     296             : of its corresponding eigenvector.  We can determine that many pairs of atoms are further appart than $r_c$ without computing the
     297             : distance between these atoms by using divide and conquer strategies such as linked lists and neighbour lists. Furthermore, we do not even
     298             : need to set a `D_MAX` parameter as we would have to if we were using [CONTACT_MATRIX](CONTACT_MATRIX.md) as the above cutoff can be determined
     299             : from the parameters of the Gaussian kernels directly.
