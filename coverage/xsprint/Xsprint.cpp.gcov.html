      26             : 
      27             : The xSPRINT coordinates, introduced in \cite ketkaew2022, extend the standard [SPRINT](SPRINT.md) coordinates
      28             : by incorporating structural information from multiple concentric spherical shells around each atom.
      29             : For a system divided into $N$ shells, the xSPRINT coordinate of atom $i$ is defined as:
      30             : 
      31             : $$
      32             : S_i^x = \begin{cases}
      33             :   S_i, & \text{if } r_{ij} < r_0 \\
      34             :   \frac{1}{\omega} \sum_{n=1}^{N} r_n\, S_i^{(n)}, & \text{otherwise}
      35             : \end{cases}
      36             : $$
      37             : 
      38             : where $S_i^{(n)}$ is the SPRINT coordinate computed from the adjacency matrix of the $n$-th shell,
      39             : $r_n = n\,r_0$ is the shell radius, $r_0$ is the user-defined cutoff for the first shell, and
      40             : $\omega = \left(\sum_{n=1}^{N} r_n\right)^2$ is a normalization weight.  Adjacency matrix elements
      41             : from inner shells are zeroed out before computing each shell's SPRINT to avoid redundancy.
      42             : 
      43             : When `NSHELLS=1` the xSPRINT coordinate reduces to the standard SPRINT coordinate.
      44             : 
      45             : The following example computes the xSPRINT coordinates for a 7-atom cluster using 3 shells
      46             : with a shell radius of 0.1:
      47             : 
      48             : ```plumed
      49             : xs: XSPRINT GROUP=1-7 SWITCH={RATIONAL R_0=0.1} R0=0.1 NSHELLS=3
      50             : PRINT ARG=xs.* FILE=colvar
      51             : ```
      52             : 
      53             : Note that `R0` defines the xSPRINT shell radius ($r_0$ in the equation) and is independent
      54             : of `R_0` inside `SWITCH`, which controls the shape of the switching function.  For shell $n$,
      55             : the switching function `R_0` is automatically set to $n \times$ `R0`.
      56             : 
      57             : This example computes xSPRINT with 2 shells for two groups of atoms:
      58             : 
      59             : ```plumed
      60             : xs: XSPRINT ...
      61             :   GROUP1=1-7 GROUP2=8-14
      62             :   SWITCH11={RATIONAL R_0=2.6 NN=6 MM=12}
      63             :   SWITCH12={RATIONAL R_0=2.2 NN=6 MM=12}
      64             :   SWITCH22={RATIONAL R_0=2.2 NN=6 MM=12}
      65             :   R0=2.0
      66             :   NSHELLS=2
      67             : ...
      68             : 
      69             : PRINT ARG=xs.* FILE=colvar
      70             : ```
      71             :
