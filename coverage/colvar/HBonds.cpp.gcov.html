      39             : /*
      40             : Calculate the number of hydrogen bonds using the Wernet-Nilsson criterion.
      41             : 
      42             : This action counts the hydrogen bonds between a set of donors (with their hydrogens) and a set of acceptors.
      43             : A donor D, one of its hydrogens H and an acceptor A form a hydrogen bond according to the criterion of Wernet and Nilsson
      44             : (the one used by the `wernet_nilsson` function of [mdtraj](https://mdtraj.org)) if
      45             : 
      46             : $$
      47             : r_{DA} < 0.33\,\textrm{nm} - 0.000044\,\textrm{nm}\,\delta_{HDA}^2
      48             : $$
      49             : 
      50             : where $r_{DA}$ is the donor-acceptor distance and $\delta_{HDA}$ is the angle, in degrees, between the D-H and the D-A vectors.
      51             : The criterion is a condition on a single variable,
      52             : 
      53             : $$
      54             : s_{DHA} = r_{DA} + k\, \delta_{HDA}^2 \qquad k = 0.000044\,\textrm{nm}/\textrm{deg}^2 \simeq 0.1444\,\textrm{nm}/\textrm{rad}^2
      55             : $$
      56             : 
      57             : which has to be smaller than 0.33 nm. The step function is replaced by a switching function of $s_{DHA}$, so that the CV is
      58             : 
      59             : $$
      60             : N_{HB} = \sum_{D} \sum_{H \in D} \sum_{A \neq D} \sigma(s_{DHA})
      61             : $$
      62             : 
      63             : and it has continuous derivatives. The default switching function is `{CUBIC D_0=0.31 D_MAX=0.35}` (in nm),
      64             : which is one below 0.31 nm, zero above 0.35 nm and 1/2 at 0.33 nm. You can change it with the SWITCH keyword
      65             : (see [LESS_THAN](LESS_THAN.md) for the available switching functions). For instance a very sharp switching function
      66             : such as `{CUBIC D_0=0.3299 D_MAX=0.3301}` reproduces the number of hydrogen bonds computed by mdtraj, but should not be used to bias a simulation.
      67             : The angle cutoff of 45 degrees that mdtraj also applies is not needed here: at that angle the criterion
      68             : already requires a donor-acceptor distance shorter than 0.24 nm.
      69             : 
      70             : The donors, the hydrogens and the acceptors are given as three lists of atoms, in any order.
      71             : Each hydrogen is assigned to the closest donor, which must be closer than 0.13 nm (a covalent D-H bond).
      72             : This assignment is done once, on the first configuration.
      73             : Hydrogens that are not bonded to any of the donors are ignored, as are the donors without hydrogens,
      74             : and the number of each is written in the log. A donor that is also an acceptor does not accept from itself.
      75             : An atom cannot be both in DONORS and in HYDROGENS, and an atom cannot be repeated in the same list.
      76             : 
      77             : The [MOLINFO](MOLINFO.md) shortcuts `@hbdonors`, `@polarhydrogens` and `@hbacceptors` select the N and O atoms bonded to a hydrogen,
      78             : the hydrogens bonded to an N or an O atom and all the N and O atoms of the reference structure respectively.
      79             : As in mdtraj, all N and O atoms are acceptors.
      80             : In the example below all the hydrogen bonds formed within a protein are counted:
      81             : 
      82             : ```plumed
      83             : #SETTINGS MOLFILE=regtest/basic/rt-hbonds/ref.pdb
      84             : MOLINFO STRUCTURE=regtest/basic/rt-hbonds/ref.pdb
      85             : hb: HBONDS DONORS=@hbdonors HYDROGENS=@polarhydrogens ACCEPTORS=@hbacceptors
      86             : PRINT ARG=hb FILE=colvar
      87             : ```
      88             : 
      89             : The atoms can also be given explicitly. This input counts the hydrogen bonds in a box of 64 water molecules,
      90             : in which the oxygens are atoms 1, 4, 7... and the hydrogens are the atoms that follow each oxygen.
      91             : The oxygens are both donors and acceptors, and a neighbor list on the donor-acceptor distance is used
      92             : (see [COORDINATION](COORDINATION.md) for the choice between NLIST and NLISTCELLS, and of NL_CUTOFF and NL_STRIDE; NL_CUTOFF should be larger than D_MAX of the switching function):
      93             : 
      94             : ```plumed
      95             : hb: HBONDS ...
      96             :   DONORS=1-192:3 HYDROGENS=2-192:3,3-192:3 ACCEPTORS=1-192:3
      97             :   SWITCH={CUBIC D_0=0.31 D_MAX=0.35}
      98             :   NLISTCELLS NL_CUTOFF=0.6 NL_STRIDE=10
      99             : ...
     100             : PRINT ARG=hb FILE=colvar
     101             : ```
     102             : 
     103             : Only N and O atoms (or other electronegative atoms) should be given as donors and acceptors:
     104             : the hydrogens bonded to any atom in DONORS are used, so if a carbon was in the list its hydrogens would be donated.
     105             : 
     106             : */
