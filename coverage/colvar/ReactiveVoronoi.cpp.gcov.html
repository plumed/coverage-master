     740             : /*
     741             : Calculate a scalar reduction of smooth Voronoi coordination defects.
     742             : 
     743             : Reactive processes such as proton transfer are difficult to describe with a
     744             : fixed molecular identity because the atom that carries the proton can change.
     745             : This Action assigns every atom in ASSIGNED continuously to the atoms in
     746             : CENTERS and reduces the resulting coordination defects to one scalar.  The
     747             : same assignment is shared by [VORONOI_DISTANCE](VORONOI_DISTANCE.md) and
     748             : [VORONOI_POSITION](VORONOI_POSITION.md).  Together the three Actions describe
     749             : the amount, separation, and location of coordination defects without
     750             : hard-coding water, glycine, a catalyst, or an atom-list position.
     751             : 
     752             : The construction follows the descriptors introduced for acid-base equilibria
     753             : \cite Grifoni2019AcidBase and condensed-phase tautomerism
     754             : \cite Grifoni2020Tautomeric.  Applications to solvated glycine, interfacial
     755             : water ions, electric-field effects, and electrocatalytic nitrogen reduction
     756             : are discussed in \cite Zhang2024Glycine, \cite Zhang2025Interfaces,
     757             : \cite Zhang2025ElectricField, and \cite Zhang2026NRR.
     758             : 
     759             : An illustrated bilingual guide with downloadable teaching structures,
     760             : application examples, performance data, and additional references is
     761             : available on the
     762             : [Reactive Soft-Voronoi CV project page](https://zhang-pchao.github.io/code/reactive-voronoi/).
     763             : 
     764             : VORONOI_COORDINATION, [VORONOI_DISTANCE](VORONOI_DISTANCE.md), and
     765             : [VORONOI_POSITION](VORONOI_POSITION.md) are part of PLUMED's default `colvar`
     766             : module and have no external library dependency.  In a PLUMED installation that
     767             : contains these Actions, use them directly in the input; no [LOAD](LOAD.md)
     768             : line or optional module is required.  Bias examples using
     769             : [OPES_METAD](OPES_METAD.md) additionally require the `opes` module.
     770             : 
     771             : ## Soft assignment and coordination defects
     772             : 
     773             : For a center \f$i\f$ and an assigned atom \f$j\f$, let \f$d_{ij}\f$ be their
     774             : minimum-image distance.  The assignment weight is
     775             : 
     776             : \f[
     777             :  w_{ij}=\frac{\exp(-\kappa d_{ij})}
     778             :  {\sum_k\exp(-\kappa d_{kj})}.
     779             : \f]
     780             : 
     781             : By default, \f$d_{ij}\f$ is evaluated with the minimum-image convention.
     782             : NOPBC instead uses the direct coordinate difference, so the input coordinates
     783             : must already follow a consistent unwrapped image convention.
     784             : 
     785             : The denominator contains all CENTERS for the same assigned atom, so
     786             : \f$\sum_i w_{ij}=1\f$.  KAPPA is positive and has inverse units of the current
     787             : PLUMED length unit.  Increasing KAPPA sharpens the assignment toward the
     788             : nearest center; reducing it spreads an assigned atom over more centers.  The
     789             : implementation uses a shifted softmax, which improves numerical stability
     790             : without changing the mathematical value.
     791             : 
     792             : For monitoring or structural diagnosis, a larger KAPPA can provide sharper
     793             : state labels once the relevant basins are already known.  For biased sampling,
     794             : a smaller KAPPA usually gives smoother assignment and force changes when an
     795             : assigned atom switches between nearby centers, although a value that is too
     796             : small can blur distinct chemical basins.  Scan KAPPA on representative
     797             : reactant, transition, product, and host-switching frames before applying a
     798             : bias.  Values such as 5 for smoother sampling or 100 for sharper diagnosis are
     799             : application examples, not transferable defaults.
     800             : 
     801             : The smooth occupancy and coordination defect of center \f$i\f$ are
     802             : 
     803             : \f[
     804             :  n_i=\sum_j w_{ij}, \qquad q_i=n_i-\nu_i .
     805             : \f]
     806             : 
     807             : REFERENCE supplies \f$\nu_i\f$.  A single value is broadcast to all CENTERS;
     808             : otherwise provide exactly one value per center in the same order as CENTERS.
     809             : For example, `REFERENCE=2` with two water O centers is the vector `(2,2)`, not
     810             : a one-center calculation.  Fractional entries are valid when the model
     811             : deliberately shares one reference occupancy over symmetry-related centers;
     812             : they should not be introduced by averaging chemically nonequivalent sites.
     813             : The identities
     814             : 
     815             : \f[
     816             :  \sum_i n_i=N_{\mathrm{assigned}}, \qquad
     817             :  \sum_i q_i=N_{\mathrm{assigned}}-\sum_i\nu_i
     818             : \f]
     819             : 
     820             : provide useful checks on a new chemical mapping.  The Action does not infer
     821             : elements, molecules, water, or a special reactive site from atom order.
     822             : CENTERS and ASSIGNED must be nonempty, internally unique, and disjoint.
     823             : 
     824             : VORONOI_COORDINATION returns
     825             : 
     826             : \f[
     827             :  Q_p=\sum_{i\in S} a_i q_i^p ,
     828             : \f]
     829             : 
     830             : where SELECT defines \f$S\f$ and COEFFICIENTS supplies \f$a_i\f$.  SELECT
     831             : defaults to all CENTERS and COEFFICIENTS defaults to one.  SIGN restricts the
     832             : sum to \f$q_i>0\f$ or \f$q_i<0\f$ when POSITIVE or NEGATIVE is selected.
     833             : 
     834             : - POWER=1 preserves the signed defect.  With sign filtering it is
     835             :   non-differentiable exactly at \f$q_i=0\f$.
     836             : - POWER=2 measures defect activity without cancellation.  With sign
     837             :   filtering its value and first derivative are continuous at \f$q_i=0\f$,
     838             :   but its second derivative has a cusp there.
     839             : - COEFFICIENTS can distinguish chemically different selected centers or
     840             :   reproduce a published scalar.  Coefficients do not change the assignment.
     841             : 
     842             : Analytical coordinate and box derivatives are provided.  The derivative with
     843             : respect to a defect is \f$a_i\f$ for POWER=1 and \f$2a_iq_i\f$ for POWER=2
     844             : inside the selected sign branch, and zero outside it.  These derivatives are
     845             : propagated through every assignment weight.  A CV intended for biasing should
     846             : avoid a POWER=1 sign boundary, a neighbor-list membership change, or another
     847             : non-smooth surface discussed below.
     848             : 
     849             : The geometric defects are not formal electronic charges.  Their physical
     850             : meaning comes from the chosen atom sets and reference occupancies and should
     851             : always be checked for the system of interest.
     852             : 
     853             : ## Translating chemistry into keywords
     854             : 
     855             : Build the input from chemistry rather than from atom-list positions:
     856             : 
     857             : 1. Put atoms that can receive an assigned atom in CENTERS.  For proton
     858             :    transfer these are commonly O and N atoms.
     859             : 2. Put only the transferable atoms in ASSIGNED.  Hydrogen atoms that cannot
     860             :    participate in the process need not be included.
     861             : 3. Give every center its neutral or intended occupancy in REFERENCE.  Typical
     862             :    examples are 2 for a water O and a model-dependent value for a reactive O
     863             :    or N.
     864             : 4. Start with the exact full-pair calculation.  Inspect representative
     865             :    neutral, product, transition, and multi-defect configurations before
     866             :    choosing SELECT, POWER, SIGN, or COEFFICIENTS.
     867             : 5. Add [VORONOI_DISTANCE](VORONOI_DISTANCE.md) only when separation is needed,
     868             :    and [VORONOI_POSITION](VORONOI_POSITION.md) only when a fixed spatial frame
     869             :    is physically meaningful.
     870             : 
     871             : REFERENCE follows CENTERS order.  COEFFICIENTS follows SELECT order.  If the
     872             : centers are reordered, reorder the corresponding numeric vector as well.
     873             : Atom-valued SELECT, GROUP1, and GROUP2 lists use absolute atom numbers and do
     874             : not rely on a center being last, first, or one of a fixed number of species.
     875             : 
     876             : ## Exact and neighbor-list calculations
     877             : 
     878             : Without NLIST, every CENTER-ASSIGNED pair is included and the finite-system
     879             : definition above is exact.  NLIST truncates the candidate centers and
     880             : renormalizes the weights over the retained candidates, so it is an
     881             : approximation rather than an algebraically exact acceleration.  Every
     882             : ASSIGNED atom must retain at least one CENTER or the calculation stops with an
     883             : error.
     884             : 
     885             : Omitting NLIST therefore has no hidden cutoff.  When NLIST is enabled,
     886             : NL_CUTOFF is an absolute CENTER-ASSIGNED distance in the active PLUMED length
     887             : units, not a bond cutoff or a water-specific constant.  If \f$d_{\min}\f$ is
     888             : the nearest-center distance and \f$R\f$ is a trial cutoff, the screening
     889             : relation
     890             : 
     891             : \f[
     892             :  \exp[-\kappa(R-d_{\min})] \le \epsilon
     893             : \f]
     894             : 
     895             : can provide an initial estimate for making a single omitted score small.
     896             : Smaller KAPPA generally requires a larger cutoff.  This estimate does not
     897             : replace convergence because omitted scores, normalization errors, and force
     898             : derivatives can accumulate over many centers.
     899             : 
     900             : NL_CUTOFF and NL_STRIDE are required whenever NLIST is present.  NL_SKIN is
     901             : optional, defaults to zero, and can be used only when NL_STRIDE is greater
     902             : than one.
     903             : 
     904             : Before using NLIST in production:
     905             : 
     906             : 1. evaluate representative configurations with the exact full-pair form;
     907             : 2. increase NL_CUTOFF until values and forces agree within the required
     908             :    tolerance;
     909             : 3. start with NL_STRIDE=1, then increase it only after checking consecutive
     910             :    MD steps.  With NL_STRIDE greater than one, NL_SKIN can add a Verlet buffer.
     911             :    The list is rebuilt early if any requested atom moves by more than half the
     912             :    skin or if the periodic box changes, while the evaluated pairs are still
     913             :    filtered at the true NL_CUTOFF on every step.
     914             : 
     915             : For replica exchange, every exchange step must also be a neighbor-list update
     916             : step.  Choose the update schedule accordingly; normally NL_STRIDE should
     917             : divide the exchange stride.
     918             : 
     919             : For a fixed box, the half-skin displacement check ensures that a pair cannot
     920             : cross NL_CUTOFF before it was present in the buffered candidate list.  A
     921             : larger skin reduces rebuilds but retains more candidate pairs, so both the
     922             : skin and stride should be benchmarked.  On PLUMED 2.11 and later, sufficiently
     923             : large periodic candidate lists use the built-in link-cell broad phase;
     924             : smaller lists retain the threaded pair scan because it is faster there.
     925             : Runtime plugins built against older PLUMED versions keep the compatible pair
     926             : scan, but can still amortize its rebuild cost with NL_SKIN.
     927             : 
     928             : A cutoff copied from another system is not a convergence test.  Pair-list
     929             : changes can introduce small discontinuities because the retained weights are
     930             : renormalized.  Prefer exact mode for derivative validation and for small or
     931             : moderate systems.  Use NLIST only after a value-and-force convergence scan
     932             : demonstrates a useful speed/accuracy tradeoff for the target system.
     933             : 
     934             : ## CPU parallelism and practical scaling
     935             : 
     936             : The exact calculation evaluates \f$N_{\mathrm{centers}}
     937             : N_{\mathrm{assigned}}\f$ pairs per step.  For water with every O in CENTERS

     951             : 
     952             : Benchmark 1, 2, 4, and 8 threads on the same frames because small candidate
     953             : lists can spend more time entering parallel regions than doing pair work, and
     954             : large lists can become limited by memory bandwidth.  Avoid CPU
     955             : oversubscription.  In a GPU molecular-dynamics run these Actions still execute
     956             : on CPUs, so a GPU allocation alone does not accelerate them.  MPI also
     957             : partitions pairs unless SERIAL is present; SERIAL is a debugging mode that
     958             : repeats the work on every rank, not a performance option.
     959             : 
     960             : For large systems, a converged NLIST is the only option here that reduces the
     961             : number of retained assignment pairs.  NL_CUTOFF controls truncation accuracy,
     962             : whereas NL_STRIDE controls how often membership is rebuilt.  Start with
     963             : NL_STRIDE=1, converge NL_CUTOFF against exact values and derivatives, and only
     964             : then test a larger stride against the maximum atomic displacement between
     965             : updates.  Report CV time per call as well as whole-simulation throughput so
     966             : that GPU force-model time and output time are not mistaken for CV cost.
     967             :

    1166             : //+PLUMEDOC COLVAR VORONOI_DISTANCE
    1167             : /*
    1168             : Calculate a distance-weighted product of smooth coordination defects.
    1169             : 
    1170             : This Action combines the continuously changing identities defined by
    1171             : [VORONOI_COORDINATION](VORONOI_COORDINATION.md) with physical center-center
    1172             : distances.  It is useful when the progress of a reactive event depends not
    1173             : only on whether defects exist, but also on how far apart the corresponding
    1174             : sites are.
    1175             : 
    1176             : ## Definition and group semantics
    1177             : 
    1178             : Let \f$q_i\f$ be the smooth coordination defect of center \f$i\f$.  When both
    1179             : GROUP1 and GROUP2 are supplied, the Action returns
    1180             : 
    1181             : \f[
    1182             :  D(G_1,G_2)=-\sum_{i\in G_1}\sum_{k\in G_2}d_{ik}q_iq_k .
    1183             : \f]
    1184             : 
    1185             : GROUP1 and GROUP2 are explicit, nonempty, disjoint subsets of CENTERS.  When
    1186             : GROUP2 is omitted, unique pairs within GROUP1 are used:
    1187             : 
    1188             : \f[
    1189             :  D(G_1)=-\sum_{\substack{i,k\in G_1\\i<k}}d_{ik}q_iq_k .
    1190             : \f]
    1191             : 
    1192             : The center-center distance \f$d_{ik}\f$ uses the minimum image unless NOPBC
    1193             : is specified.  CENTERS, ASSIGNED, KAPPA, REFERENCE, NOPBC, and NLIST have the
    1194             : same meaning as on the VORONOI_COORDINATION page.  NLIST truncates only the
    1195             : CENTER-ASSIGNED candidates used to construct the defects; it never removes
    1196             : GROUP1/GROUP2 center-center reduction pairs.
    1197             : 
    1198             : The product \f$q_iq_k\f$ emphasizes pairs of centers carrying correlated or
    1199             : complementary defects without assigning a permanent ion identity.  For one
    1200             : positive and one negative defect, the overall minus sign makes the leading
    1201             : term positive and approximately equal to their separation when the defects
    1202             : approach +1 and -1.  Multiple defects generate a sum over all requested
    1203             : pairs; the output should not then be interpreted automatically as one unique
    1204             : ion-ion distance.
    1205             : 
    1206             : ## Derivatives, periodicity, and bias suitability
    1207             : 
    1208             : Both contributions to the derivative are included: the direct derivative of
    1209             : \f$d_{ik}\f$ and the chain-rule derivative of every \f$q_i\f$ through the
    1210             : soft assignment.  Analytical box derivatives are also provided using the
    1211             : same minimum-image vectors.  The Action stops if a requested center-center
    1212             : distance is zero or non-finite because its radial derivative is then
    1213             : undefined.
    1214             : 
    1215             : The exact full-pair assignment is smooth away from coincident atoms and the
    1216             : usual minimum-image branch surfaces.  NLIST uses the approximate truncated
    1217             : normalization described on the VORONOI_COORDINATION page and may add
    1218             : membership discontinuities.  Validate the exact Action with numerical
    1219             : derivatives before biasing it, and converge values and forces separately if
    1220             : NLIST is required.
    1221             : 
    1222             : VORONOI_DISTANCE is not normalized by the amount of defect.  It naturally
    1223             : approaches zero in a neutral configuration, but its magnitude also changes as
    1224             : defects form or disappear.  This coupling is often desired in a reaction
    1225             : coordinate; if a pure conditional distance is intended, its low-defect limit
    1226             : must be defined explicitly rather than obtained by dividing by a nearly zero
    1227             : weight.
    1228             : 
    1229             : ## Choosing GROUP1 and GROUP2
    1230             : 
    1231             : - Use GROUP1 without GROUP2 for separation among possible sites in one pool,
    1232             :   such as water O atoms that can host a hydronium or hydroxide defect.
    1233             : - Use both groups for cross separation between two chemical pools, such as
    1234             :   water O atoms and one reactive N or O site.
    1235             : - Combine multiple VORONOI_DISTANCE Actions with
    1236             :   [COMBINE](COMBINE.md) when a published CV contains several physically
    1237             :   distinct pair sets.  Keeping the pair sets explicit avoids hidden
    1238             :   chemistry and atom-order rules.
    1239             :

    1354             : ## Troubleshooting
    1355             : 
    1356             : - `GROUP1 must contain at least two atoms when GROUP2 is omitted`: a
    1357             :   within-group distance requires at least one unique pair.  For a single
    1358             :   reactive site, use a nonempty disjoint GROUP2.
    1359             : - `GROUP1 and GROUP2 must be disjoint`: a self-pair has no valid radial
    1360             :   derivative and is intentionally rejected.
    1361             : - A distance is unexpectedly negative: same-sign defect pairs contribute
    1362             :   negatively because of the leading minus sign.  Inspect the individual
    1363             :   defects and pair-set definition before changing the sign convention.
    1364             : - A value grows with the number of defects: the Action is a pair sum, not a
    1365             :   normalized nearest-pair distance.  Reduce the groups or define a different

    1475             : Calculate a defect-weighted Cartesian position relative to a fixed origin.
    1476             : 
    1477             : Molecular identity alone does not say where a hydronium, hydroxide, or another
    1478             : coordination defect is located.  This Action weights the coordinates of the
    1479             : possible host centers by the smooth defects defined in
    1480             : [VORONOI_COORDINATION](VORONOI_COORDINATION.md).  It replaces atom-list-index
    1481             : moments with a physical Cartesian coordinate and provides analytical
    1482             : coordinate and box derivatives.
    1483             : 
    1484             : Legacy index-weighted observables such as \f$\sum_i i q_i^2\f$ depend on the
    1485             : order in which centers are listed: reordering chemically identical input can
    1486             : change the value even when the configuration is unchanged.  Such an index is
    1487             : useful at most as an internal diagnostic and is a poor general bias coordinate.
    1488             : It is intentionally not reproduced here.  Use SELECT and a physical
    1489             : VORONOI_POSITION coordinate when the spatial location of a defect is needed.
    1490             : 
    1491             : ## Definition
    1492             : 
    1493             : For selected centers \f$S\f$, Cartesian axis \f$\alpha\f$, and fixed origin
    1494             : \f$x_0\f$, define the displacement
    1495             : 
    1496             : \f[
    1497             :  u_i=\operatorname{minimage}(x_{i,\alpha}-x_0)
    1498             : \f]
    1499             : 
    1500             : when periodic boundaries are active.  NOPBC replaces it by the direct
    1501             : Cartesian difference.  The unnormalized Action is
    1502             : 
    1503             : \f[
    1504             :  P=\sum_{i\in S}g(q_i)f(u_i),
    1505             : \f]
    1506             : 
    1507             : where \f$g(q_i)=q_i^2\f$ for defects retained by SIGN and zero for excluded
    1508             : defects.  The spatial function is \f$f(u)=u\f$ by default and
    1509             : \f$f(u)=|u|\f$ with ABSOLUTE.  SELECT defaults to all CENTERS.
    1510             : 
    1511             : With NORMALIZE, the returned value is
    1512             : 
    1513             : \f[
    1514             :  \bar P=\frac{\sum_i g(q_i)f(u_i)}{\sum_i g(q_i)}.
    1515             : \f]
    1516             : 
    1517             : The unnormalized form naturally approaches zero in a neutral configuration
    1518             : and measures position multiplied by defect activity.  The normalized form is
    1519             : a defect-weighted mean position, but is defined only when a selected defect is
    1520             : present.  If its denominator is no larger than TOLERANCE, the Action stops
    1521             : instead of returning a NaN or an arbitrarily amplified coordinate.
    1522             : 
    1523             : ## Selecting the observable
    1524             : 
    1525             : - SIGN=POSITIVE tracks over-coordinated centers; SIGN=NEGATIVE tracks
    1526             :   under-coordinated centers; SIGN=ALL includes both.
    1527             : - ABSOLUTE measures distance from the fixed origin.  Without ABSOLUTE, the
    1528             :   sign of the selected Cartesian side is retained.
    1529             : - NORMALIZE removes the magnitude of the total squared defect.  Use it only
    1530             :   when the relevant defect is guaranteed to exist throughout the sampled
    1531             :   region.
    1532             : - SELECT restricts possible hosts, for example to water O atoms while leaving
    1533             :   a reactive molecular site in CENTERS for the shared assignment.
    1534             : 
    1535             : The sign-gated squared weight has a continuous first derivative at
    1536             : \f$q_i=0\f$ but a discontinuous second derivative.  ABSOLUTE is
    1537             : non-differentiable at \f$u_i=0\f$.  Without ABSOLUTE, the direct Cartesian
    1538             : derivative is smooth away from the periodic branch cut.
    1539             :

    1541             : 
    1542             : The implementation differentiates both the defect weight and the selected
    1543             : center coordinate.  With NORMALIZE, the quotient rule is evaluated
    1544             : analytically.  Box derivatives use the same periodic images as the value.
