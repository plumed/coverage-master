      40             : /*
      41             : Calculate the minimum distance between a whole group and a distinct periodic image of itself.
      42             : 
      43             : For whole coordinates $r_i$, the result is
      44             : \f[ d=\min_{i,j;\,n\in\mathbb{Z}^3\setminus\{0\}}|r_j-r_i+B^T n|, \f]
      45             : where cell vectors are rows of $B$. Zero translation is excluded for ALL pairs.
      46             : An atom and its own translated image are valid candidates: for one atom this
      47             : returns the shortest nonzero lattice-vector length, not zero.
      48             : 
      49             : ## Whole coordinates
      50             : 
      51             : This action neither reconstructs nor wraps coordinates. Use
      52             : [WHOLEMOLECULES](WHOLEMOLECULES.md) first if atoms are individually wrapped:
      53             : 
      54             : ```plumed
      55             : WHOLEMOLECULES ENTITY0=1-100
      56             : img: IMAGE_DISTANCE ATOMS=1-100
      57             : LOWER_WALLS ARG=img AT=0.8 KAPPA=1000 EXP=2
      58             : PRINT ARG=img FILE=COLVAR
      59             : ```
      60             : 
      61             : Consecutive atoms in ENTITY0 must remain sufficiently close for unambiguous
      62             : minimum-image reconstruction; see WHOLEMOLECULES. Connecting atoms can be included
      63             : in ENTITY0 without being selected in ATOMS. An arbitrary disconnected group has
      64             : no unique reconstruction. Once whole, the scalar is independent of selection
      65             : order and coherent translations, including lattice translations. Individually
      66             : wrapping atoms without reconstruction changes the specified copy and can change
      67             : the result. There is no maximum extent or compactness assumption.
      68             : 
      69             : ## Guaranteed search and cost
      70             : 
      71             : A nonsingular three-dimensional periodic cell is required; orthorhombic and
      72             : triclinic cells are supported. After lattice reduction, define
      73             : $s=B^{-T}(r_j-r_i)$ and $g_k=|(B^{-1})_{:,k}|$. A candidate of length at most
      74             : $R$ satisfies $|s_k+n_k|\le Rg_k$. Enumerating these bounded integer intervals
      75             : includes every possible improvement. Initially $R$ is a nonzero basis-vector
      76             : length. Reduction changes neither the lattice nor the zero translation.
      77             : Bounds are padded outwards for floating point roundoff. This search includes
      78             : extended groups and does not assume 26 neighboring images suffice.
      79             : As with other geometric CVs, extremely ill-conditioned cells and coordinates
      80             : beyond floating point/integer resolution are unsuitable; unrepresentable integer
      81             : bounds are rejected.
      82             : 
      83             : For at least 64 atoms, the default search rebuilds a balanced Cartesian spatial
      84             : tree from the whole coordinates every frame. If $w_k$ is the span of their
      85             : reduced fractional coordinates, every improving image satisfies
      86             : $|n_k|\le w_k+Rg_k$. These globally bounded nonzero shifts are queried against
      87             : the tree. The Cartesian distance to a node's bounding box is a lower bound on
      88             : all distances to atoms in that node, so nodes farther than the current winner
      89             : are skipped. Surviving leaves evaluate the same displacement as the exhaustive
      90             : pair kernel. Conservative padding retains tied candidates and protects the
      91             : broad phase against floating point cancellation and changes of origin.
      92             : 
      93             : The tree is rebuilt on every calculation, including changes of the cell and
      94             : whole coordinates; there is no cached neighbor list, skin or update stride.
      95             : BRUTE_FORCE disables this spatial pruning for validation. Small selections and
      96             : frames requiring more than 4096 globally bounded shifts use the original exact
      97             : pair scan instead. The scan is also used when the shift count exceeds
      98             : $\max(32,N/8)$, avoiding excessive image queries for sparse extended groups. This fallback adds no restriction on group extent or cell
      99             : geometry. Tree construction costs $O(N\log N)$; query cost depends on geometry,
     100             : and worst-case pair work remains quadratic. The exhaustive scan costs $O(N^2K)$
     101             : for $K$ bounded image candidates per pair. No pair/image matrix is stored.
     102             : 
     103             : Atom query rows are distributed cyclically over the action MPI communicator and
     104             : scheduled dynamically over OpenMP threads on each rank. Each worker keeps its
     105             : own minimum; a deterministic reduction selects the same winning pair and image
     106             : regardless of rank/thread count. Final atomic and box gradients are replicated
     107             : using normal Colvar force propagation. MPI exchanges one winner per rank.
     108             : Storage per rank is $O(N+S+T+P)$ for $S$ shifts, $T$ threads and $P$ ranks, with
     109             : $S$ bounded by the fallback threshold. OpenMP is disabled below 4096 local
     110             : potential pairs per requested thread; MPI communication and replicated tree
     111             : construction can dominate small selections. PLUMED_NUM_THREADS controls the
     112             : OpenMP thread count. SERIAL disables both forms of work sharing and retains the
     113             : spatial search. Benchmark representative geometry before production use.
     114             : 
     115             : ## Biasing and derivatives
     116             : 
     117             : The exact minimum is continuous but piecewise differentiable; forces can jump at
     118             : pair/image switches. Exact ties use the initial self-image basis vector / first strict self-image
     119             : improvement, followed by the lexicographically smallest selection-index pair
     120             : and reduced-basis integer shift. This reproduces the serial traversal order
     121             : independently of OpenMP scheduling and MPI rank count. This is one branch's
     122             : derivative, not a unique gradient at a cusp; selection order or basis changes
     123             : can affect derivatives at a tie. Biasing this exact scalar is supported with
     124             : that caveat. No smooth minimum is provided. MIN/ALT_MIN reductions define other
     125             : quantities whose image truncation and multiplicities would need specification;
     126             : an adaptive winner-only candidate set cannot simply be softened.
     127             : 
     128             : For the active $v=r_j-r_i+B^Tn$, atomic gradients are $-v/d,+v/d$ and cancel
     129             : for $i=j$. The PLUMED box derivative is $-v\otimes(v/d)$ under homogeneous
     130             : coordinate and cell deformation, including the image shift. Thus one atom
     131             : has a box derivative despite zero atomic gradients. Empty selections,
     132             : nonfinite inputs, missing/singular boxes and exactly coincident image contacts
     133             : are errors; at zero contact the distance gradient is undefined.
     134             : */
