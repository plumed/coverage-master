      40             : /*
      41             : Calculate eRMSD with respect to a reference structure.
      42             : 
      43             : eRMSD is a metric developed for measuring distances between three-dimensional RNA structures.
      44             : The standard RMSD measure is highly inaccurate when measuring distances among three-dimensional
      45             : structures of nucleic acids.
      46             : It is not unusual, for example, that two RNA structures with low RMSD (i.e. less than 0.4nm) display a completely different network of base-base interactions.
      47             : 
      48             : eRMSD measures the distance between structures by considering only the relative positions and orientations of nucleobases. The eRMSD can be considered as a vectorial version of contact maps and it is calculated as follows:
      49             : 
      50             : 1. Set up a local reference system in the center of the six-membered ring of each nucleobase in a molecule.
      51             :    The xy plane lies on the plane of the nucleobase, and it is oriented such that the Watson-Crick interaction is always at $\theta\approx 60^{\circ}$.
      52             : 
      53             : 2. Calculate all pairwise distance vectors $\vec{r}_{i,j}$ among base centers.
      54             : 
      55             : 3. Rescale distance vectors as $\tilde{\vec{r}}_{i,j}=(r_x/a,r_y/a,r_z/b)$, where a=5 Angstrom and b=3 Angstrom. This rescaling has the effect of weighting more deviations on the z-axis with respect to the x/y directions.
      56             : 
      57             : 4. Calculate the G vectors
      58             : 
      59             : $$
      60             : \vec{G}(\tilde{\vec{r}}) = (\sin(\gamma \tilde{r}) \tilde{r}_x/\tilde{r},\sin(\gamma \tilde{r}) \tilde{r}_y/\tilde{r},\sin(\gamma \tilde{r}) \tilde{r}_z/\tilde{r}, 1+\cos(\gamma \tilde{r})) \times
      61             : \frac{\Theta(\tilde{r}_{cutoff}-\tilde{r})}{\gamma}
      62             : $$
      63             : 
      64             : Here, $ \gamma = \pi/\tilde{r}_{cutoff}$ and $ \Theta $ is the Heaviside step function. The default cutoff is set to 2.4.
      65             : 
      66             : 5. The eRMSD between two structures $ \alpha $ and $ \beta $ reads
      67             : 
      68             : $$
      69             : eRMSD = \sqrt{\frac{1}{N} \sum_{j,k} \vert \vec{G}(\tilde{\vec{r}}_{jk}^{\alpha}) - \vec{G}(\tilde{\vec{r}}_{jk}^{\beta}) \vert^2 }
      70             : $$
      71             : 
      72             : Using the default cutoff, two structures with eRMSD of 0.7 or lower can be considered as significantly similar. A full description of the eRMSD can be found in the first paper in the bibliography below.
      73             : 
      74             : ERMSD is computed using the position of three atoms on the 6-membered ring of each involved nucleobase. The atoms should be:
      75             : - C2,C4,C6 for pyrimdines
      76             : - C2,C6,C4 for purines
      77             : 
      78             : The different order for purines and pyrimidines is fundamental and allows you to compute ERMSD between structures with different
      79             : sequences as well! Notice that the simplest way to avoid mistakes in choosing these atoms is to use the `@lcs-#` strings
      80             : as shown in the examples (see also [MOLINFO](MOLINFO.md)).
      81             : 
      82             : !!! caution "ERMSD paths not possible"
      83             : 
      84             :     Notice that the ERMSD implemented here is not integrated with the other metrics in plumed. As a consequence, it is not (yet) possible
      85             :     to e.g. build path collective variables using ERMSD
      86             : 
      87             : !!! caution "ERMSD with multiple molecules"
      88             : 
      89             :     Notice that ERMSD expect a single molecule and makes coordinates whole before anything else. As such, results might be unexpected
      90             :     for a multi molecular system.
      91             : 
      92             : ## Pair search
      93             : 
      94             : By default, a buffered neighbor list is built using PLUMED linked cells.
      95             : The search sphere encloses the anisotropic cutoff ellipsoid: its radius is
      96             : `CUTOFF/2`, corresponding to the longest semiaxis. The default buffer is one sixth
      97             : of this radius; `NL_BUFFER`, expressed in the selected length unit (nm by default),
      98             : can override it. The list is rebuilt whenever any
      99             : base center moves more than half the buffer from its position at the last build.
     100             : Centers are checked on every evaluation, so no update stride is required.
     101             : Base rotations do not invalidate the enclosing sphere. Reference contacts are
     102             : retained even when the corresponding instantaneous contact disappears.
     103             : 
     104             : Use `PAIR_SEARCH=CELLS` to rebuild an unbuffered linked-cell list each evaluation,
     105             : or `PAIR_SEARCH=DIRECT` to visit every pair. These give the same metric and
     106             : analytical derivatives. Pair evaluation uses OpenMP and the action MPI communicator.
     107             : 
     108             : ## Examples
     109             : 
     110             : Calculate the eRMSD from reference structure reference.pdb using the default cutoff (2.4). The list of residues involved in the calculation has to be specified. In this example, the eRMSD is calculated
     111             : considering residues 1,2,3,4,5,6.
     112             : 
     113             : ```plumed
     114             : #SETTINGS MOLFILE=regtest/basic/rt-ermsd/ref.pdb
     115             : MOLINFO STRUCTURE=regtest/basic/rt-ermsd/ref.pdb
     116             : eRMSD1: ERMSD REFERENCE=regtest/basic/rt-ermsd/ref.pdb ATOMS=@lcs-1,@lcs-2,@lcs-3,@lcs-4,@lcs-5,@lcs-6
     117             : ```
     118             : 
     119             : */
