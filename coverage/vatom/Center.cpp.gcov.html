      32             : /*
      33             : Calculate the center for a group of atoms, with arbitrary weights.
      34             : 
      35             : The position of the center ${r}_{\rm COM}$ given by:
      36             : 
      37             : $$
      38             : {r}_{\rm COM}=\frac{\sum_{i=1}^{n} {r}_i\ w_i }{\sum_i^{n} w_i}
      39             : $$
      40             : 
      41             : In these expressions $r_i$ indicates the position of atom $i$ and $w_i$ is the weight for atom $i$. The following input
      42             : shows how you can calculate the expressions for a set of atoms by using PLUMED:
      43             : 
      44             : ```plumed
      45             : # This action calculates the position of the point on the line connecting atoms 1 and 10 that is
      46             : # twice as far atom 10 as it is from atom 1
      47             : c1: CENTER ATOMS=1,1,10
      48             : # this is another way of calculating this position
      49             : c1bis: CENTER ATOMS=1,10 WEIGHTS=2,1
      50             : 
      51             : DUMPATOMS ATOMS=c1,c1bis FILE=atoms.xyz
      52             : ```
      53             : 
      54             : Notice that center's position is stored as [a virtual atom](specifying_atoms.md). The positions of the centers in the above input
      55             : used in the DUMPATOMS command by using the labels for the CENTER actions. Notice, furthermore, that the mass and charge of this new center
      56             : are equal to the sums of the masses and charges of the input atoms.
      57             : 
      58             : The input below shows how you can use the CENTER action in place of the [COM](COM.md) action to calculate the center of mass for a group of atoms.
      59             : 
      60             : ```plumed
      61             : c: CENTER ATOMS=1-5 MASS
      62             : ```
      63             : 
      64             : Center is more powerful than COM because you can use arbitrary vectors of weights as in the first example above or vector of weights that are calculated by
      65             : another action as has been done in the input below.
      66             : 
      67             : ```plumed
      68             : fcc: FCCUBIC SPECIES=1-1000 SWITCH={RATIONAL D_0=3.0 R_0=1.5}
      69             : sfcc: MORE_THAN ARG=fcc SWITCH={RATIONAL R_0=0.5}
      70             : c: CENTER ATOMS=1-1000 WEIGHTS=sfcc
      71             : DUMPATOMS ATOMS=c FILE=atom.xyz
      72             : ```
      73             : 
      74             : This input assumes you have a cluster of solid atoms in a liquid. The actions with labels `fcc` and `sfcc`
      75             : are used to differentiate between atoms in solid-like and liquid-like atoms. `sfcc` is thus a vector with
      76             : one element for each atom. These elements are equal to one if the environment around the corresponding atom
      77             : are solid like and zero if the environment around the atom is liquid like.
      78             : 
      79             : ## A note on periodic boundary conditions
      80             : 
      81             : If you run with periodic boundary conditions
      82             : these are taken into account automatically when computing the center of mass. The way this is
      83             : handled is akin to the way molecules are rebuilt in the [WHOLEMOLECULES](WHOLEMOLECULES.md) command.
      84             : However, at variance to [WHOLEMOLECULES](WHOLEMOLECULES.md), the copies of the atomic positions in this
      85             : action are modified.  The global positions (i.e. those that are used in all other actions)
      86             : are not changed when the alignment is performed.
      87             : 
      88             : If you believe that PBC should not be applied when calculating the position fo the center of mass you can use the
      89             : NOPBC flag as shown below:
      90             : 
      91             : ```plumed
      92             : c: CENTER ATOMS=1-100 NOPBC
      93             : ```
      94             : 
      95             : An additional way of managing periodic boundary conditions is offered in CENTER by using the PHASES keyword as shown
      96             : in the example input below
      97             : 
      98             : ```plumed
      99             : c: CENTER ATOMS=1-100 PHASES
     100             : ```
     101             : 
     102             : The scaled value for the $x$ component of the position of the center is calculated from the scaled components of the input atoms, $x_i$,
     103             : using the following expression when the PHASES option is employed
     104             : 
     105             : $$
     106             : x_\textrm{com} = \frac{1}{2\pi} \arctan\left( \frac{\sum_{i=1}^n w_i \sin(2 \pi x_i ) }{ \sum_{i=1}^n w_i \cos(2 \pi x_i ) } \right)
     107             : $$
     108             : 
     109             : Similar, expressions are used to calculae the values of the scaled $y$ and $z$ components.  The final cartesian coordinates of the center are then computed
     110             : by multiplying these scaled components by the cell vectors.  Notice that by construction this center position is
     111             : not invariant with respect to rotations of the atoms at fixed cell lattice.
     112             : In addition, for symmetric Bravais lattices, it is not invariant with respect
     113             : to special symmetries. E.g., if you have an hexagonal cell, the center will
     114             : not be invariant with respect to rotations of 120 degrees.
     115             : On the other hand, it might make the treatment of PBC easier in difficult cases.
     116             : 
     117             : As an alternative to PHASES you can use the SAFE_PHASES flag as shown below:
     118             : 
     119             : ```plumed
     120             : c: CENTER ATOMS=1-100 SAFE_PHASES
     121             : ```
     122             : 
     123             : This option will use the method described above for the PHASES keyword if the cell coordinates are set.  If, however, the cell coordinates are not set the
     124             : position of the center will be calculated in the usual way.  We wouldn't recommend using this option in place of PHASES as additional computational overhead
     125             : is introduced.  Furthermore, you normally know if the cell parameters are not passed to PLUMED in advance of doing the calculation
     126             :
