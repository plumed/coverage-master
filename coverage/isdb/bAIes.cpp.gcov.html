      43             : /*
      44             : Bayesian refinement of AF models.
      45             : 
      46             : This action implements the Bayesian approach to refine AlphaFold (AF) models (bAIes) that is introduced in the papers cited below.
      47             : It can be used to generate conformational ensembles of intrinsically disordered proteins (IDPs), as discussed in the first paper, or to refine AF models prior to small-molecule virtual screening, as discussed in the second paper.
      48             : 
      49             : The distances $d_{ij}$ between the pairs of atoms listed in DATA_FILE are restrained to the distributions predicted by AF.
      50             : For each pair, the AF distogram is fitted with either a Gaussian distribution, in which case the energy is
      51             : 
      52             : $$
      53             : E = \frac{k_B T}{2} \sum_{ij} \left( \frac{d_{ij} - \mu_{ij}}{\sigma_{ij}} \right)^2,
      54             : $$
      55             : 
      56             : or a log-normal distribution, in which case $d_{ij}$ is replaced by $\log d_{ij}$ in the expression above.
      57             : When PRIOR=JEFFREYS or PRIOR=CAUCHY is used, the uncertainty of each restraint is treated as an unknown parameter that is marginalized
      58             : using a Jeffreys or a Cauchy prior, with $\sigma_{ij}$ acting as its lower bound. This results in an energy that grows more slowly than the harmonic one for large deviations
      59             : and is thus more tolerant of errors in the AF predictions. PRIOR=NONE gives the energy above.
      60             : SIGMA_MIN sets a lower bound for all the $\sigma_{ij}$ read from DATA_FILE. The energy is stored in the `ene` component.
      61             : 
      62             : DATA_FILE contains one line per restrained pair, with the serial numbers of the two atoms (which must be included in ATOMS), $\mu_{ij}$ and $\sigma_{ij}$ (in PLUMED length units, or of the logarithm of the distance for the log-normal model).
      63             : The noise model is set with the `model` field in the header, which can be `gaussian` or `lognormal`, as in the following example:
      64             : 
      65             : ````
      66             : #! FIELDS Id atom_i atom_j mu sigma
      67             : #! SET model gaussian
      68             : 0 1 16 0.23321 0.07263
      69             : 1 1 23 0.56752 0.06087
      70             : 2 1 29 0.81512 0.10485
      71             : ````
      72             : 
      73             : ## Examples
      74             : 
      75             : The following input restrains the distances between the atoms listed in DATA_FILE and applies the resulting energy as a bias.
      76             : 
      77             : ```plumed
      78             : #SETTINGS INPUTFILES=regtest/isdb/rt-baies/gauss.dat
      79             : baies: BAIES ...
      80             :   ATOMS=1,5,7,16,18,20,23,25,27,29,33,35,37,39,43,45,47,49,67,69,71,73,77,79,81,83,87,89,91,93,98,102,104
      81             :   DATA_FILE=regtest/isdb/rt-baies/gauss.dat
      82             :   PRIOR=JEFFREYS
      83             :   TEMP=300
      84             : ...
      85             : BIASVALUE ARG=baies.ene
      86             : PRINT ARG=baies.ene FILE=colvar STRIDE=100
      87             : ```
      88             : 
      89             : A complete tutorial for IDPs can be found [here](https://github.com/COSBlab/bAIes-IDP).
      90             : 
      91             : */
