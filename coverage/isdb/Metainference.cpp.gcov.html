      32             : Calculates the Metainference energy for a set of experimental data.
      33             : 
      34             : The metainference method that is introduced in the first paper cited below is a Bayesian framework
      35             : to model heterogeneous systems by integrating prior information with noisy, ensemble-averaged data.
      36             : Metainference models a system and quantifies the level of noise in the data by considering a set of replicas of the system.
      37             : 
      38             : Calculated experimental data are given in input as ARG while reference experimental values
      39             : can be given either from fixed components of other actions using PARARG or as numbers using
      40             : PARAMETERS. The default behavior is that of averaging the data over the available replicas,
      41             : if this is not wanted the keyword NOENSEMBLE prevent this averaging.
      42             : 
      43             : Metadynamics Metainference (see second paper cited below) more in general biased Metainference requires the knowledge of
      44             : biasing potential in order to calculate the weighted average. In this case the value of the bias
      45             : can be provided as the last argument in ARG and adding the keyword REWEIGHT. To avoid the noise
      46             : resulting from the instantaneous value of the bias the weight of each replica can be averaged
      47             : over a give time using the keyword AVERAGING.
      48             : 
      49             : The data can be averaged by using multiple replicas and weighted for a bias if present.
      50             : The functional form of Metainference can be chosen among four variants selected
      51             : with NOISE=GAUSS,MGAUSS,OUTLIERS,MOUTLIERS,GENERIC which correspond to modelling the noise for
      52             : the arguments as a single gaussian common to all the data points, a gaussian per data
      53             : point, a single long-tailed gaussian common to all the data points, a log-tailed
      54             :  gaussian per data point or using two distinct noises as for the most general formulation of Metainference.
      55             : In this latter case the noise of the replica-averaging is gaussian (one per data point) and the noise for
      56             : the comparison with the experimental data can chosen using the keyword LIKELIHOOD
      57             : between gaussian or log-normal (one per data point), furthermore the evolution of the estimated average
      58             : over an infinite number of replicas is driven by DFTILDE.
      59             : 
      60             : As for Metainference theory there are two sigma values: SIGMA_MEAN0 represent the
      61             : error of calculating an average quantity using a finite set of replica and should
      62             : be set as small as possible following the guidelines for replica-averaged simulations
      63             : in the framework of the Maximum Entropy Principle. Alternatively, this can be obtained
      64             : automatically using the internal sigma mean optimization as introduced in the third paper cited below
      65             : (OPTSIGMAMEAN=SEM), in this second case sigma_mean is estimated from the maximum standard error
      66             : of the mean either over the simulation or over a defined time using the keyword AVERAGING.
      67             : SIGMA_BIAS is an uncertainty parameter, sampled by a MC algorithm in the bounded interval
      68             : defined by SIGMA_MIN and SIGMA_MAX. The initial value is set at SIGMA0. The MC move is a
      69             : random displacement of maximum value equal to DSIGMA. If the number of data point is
      70             : too large and the acceptance rate drops it is possible to make the MC move over mutually
      71             : exclusive, random subset of size MC_CHUNKSIZE and run more than one move setting MC_STEPS
      72             : in such a way that MC_CHUNKSIZE*MC_STEPS will cover all the data points.
      73             : 
      74             : Calculated and experimental data can be compared modulo a scaling factor and/or an offset
      75             : using SCALEDATA and/or ADDOFFSET, the sampling is obtained by a MC algorithm either using
      76             : a flat or a gaussian prior setting it with SCALE_PRIOR or OFFSET_PRIOR. With a flat prior the
      77             : moves are reflected into the interval given by SCALE_MIN and SCALE_MAX (OFFSET_MIN and OFFSET_MAX),
      78             : with a gaussian prior the prior is centered in SCALE0 (OFFSET0) and its width is DSCALE (DOFFSET),
      79             : which also sets the size of the moves.
      80             : 
      81             : The random numbers of the Monte Carlo are seeded from the clock, so that two runs are different;
      82             : SEED makes them reproducible. The status of Metainference (uncertainties, history of sigma mean,
      83             : scale, offset, averaged weights) is written every WRITE_STRIDE steps in the file MISTATUS followed
      84             : by the label of the action (STATUS_FILE changes MISTATUS) and is read back when restarting.
      85             : 
      86             : The same keywords can be used in the ISDB collective variables (e.g. [NOE](NOE.md), [RDC](RDC.md))
      87             : together with DOSCORE: in this case the score is calculated directly by the collective variable,
      88             : which is faster with many data.
      89             : 
      90             : ## Examples
      91             : 
      92             : In the following example we calculate a set of [RDC](RDC.md), take the replica-average of
      93             : them and comparing them with a set of experimental values. RDCs are compared with

      95             : MC on-the-fly
