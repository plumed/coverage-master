      30             : /*
      31             : Calculates the (Residual) Dipolar Coupling between two atoms.
      32             : 
      33             : The Dipolar Coupling between two nuclei depends on the $\theta$ angle between
      34             : the inter-nuclear vector and the external magnetic field.
      35             : 
      36             : $$
      37             : D=D_{max}0.5(3\cos^2(\theta)-1)
      38             : $$
      39             : 
      40             : where
      41             : 
      42             : $$
      43             : D_{max}=-\mu_0\gamma_1\gamma_2h/(8\pi^3r^3)
      44             : $$
      45             : 
      46             : that is the maximal value of the dipolar coupling for the two nuclear spins with gyromagnetic ratio $\gamma$.
      47             : $\mu$ is the magnetic constant and h is the Planck constant.
      48             : 
      49             : Common Gyromagnetic Ratios (C.G.S)
      50             : - H(1) 26.7513
      51             : - C(13) 6.7261
      52             : - N(15) -2.7116
      53             : and their products (this is what is given in input using the keyword GYROM)
      54             : - N-H -72.5388
      55             : - C-H 179.9319
      56             : - C-N -18.2385
      57             : - C-C 45.2404
      58             : 
      59             : In isotropic media DCs average to zero because of the rotational
      60             : averaging, but when the rotational symmetry is broken, either through the introduction of an alignment medium or for molecules
      61             : with highly anisotropic paramagnetic susceptibility, then the average of the DCs is not zero and it is possible to measure a Residual Dipolar Coupling (RDCs).
      62             : 
      63             : This collective variable calculates the Dipolar Coupling for a set of couple of atoms using
      64             : the above definition.
      65             : 
      66             : In a standard MD simulation the average over time of the DC should then be zero. If one wants to model the meaning of a set of measured RDCs it is possible to try to solve the following problem: "what is the distribution of structures and orientations that reproduce the measured RDCs".
      67             : 
      68             : This collective variable can then be use to break the rotational symmetry of a simulation by imposing that the average of the DCs over the conformational ensemble must be equal to the measured RDCs as discussed in the first of the papers cited below. Since measured RDCs are also a function of the fraction of aligned molecules in the sample it is better to compare them modulo a constant or looking at the correlation.
      69             : 
      70             : Replica-Averaged simulations can be performed using RDCs, [ENSEMBLE](ENSEMBLE.md), [STATS](STATS.md) and [RESTRAINT](RESTRAINT.md).
      71             : [METAINFERENCE](METAINFERENCE.md) can be activated using DOSCORE and the other relevant keywords.
      72             : 
      73             : Additional material and examples can be also found in the tutorials
      74             : 
      75             : ## Examples
      76             : 
      77             : In the following example five N-H RDCs are defined and averaged over multiple replicas,
      78             : their correlation is then calculated with respect to a set of experimental data and restrained.
      79             : In addition, and only for analysis purposes, the same RDCs each single conformation are calculated
      80             : using a Single Value Decomposition algorithm, then averaged and again compared with the experimental data.
      81             : 
      82             : ```plumed
      83             : #SETTINGS NREPLICAS=2
      84             : RDC ...
      85             : GYROM=-72.5388
      86             : SCALE=0.001
      87             : ATOMS1=20,21

      92             : LABEL=nh
      93             : ... RDC

      95             : erdc: ENSEMBLE ARG=nh.*

      97             : st: STATS ARG=erdc.* PARAMETERS=8.17,-8.271,-10.489,-9.871,-9.152
      98             :
