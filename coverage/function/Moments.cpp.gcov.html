      36             : Calculate central moments from the distribution of input quantities

      38             : This action takes a set of $N$ input arguments, $s_i$, and evaluates the $k$th central moment of the distribution of input arguments using:

      40             : $$

      42             : $$
      43             : 
      44             : A single moments action can evaluate more than one central moment at once so, for example, the input below can be used to calculate the second
      45             : and third central moment for the distribution of the four input distances.
      46             : 
      47             : ```plumed
      48             : d12:  DISTANCE ATOMS=1,2
      49             : d13:  DISTANCE ATOMS=1,3
      50             : d14:  DISTANCE ATOMS=1,4
      51             : d15:  DISTANCE ATOMS=1,5

      53             : PRINT ARG=mv.moment-2,mv.moment-3 FILE=colvar
      54             : ```
      55             : 
      56             : Notice that you can also achieve the same result using the following input:
      57             : 
      58             : ```plumed
      59             : d: DISTANCE ATOMS1=1,2 ATOMS2=1,3 ATOMS3=1,4 ATOMS4=1,5
      60             : mv: MOMENTS ARG=d POWERS=2,3
      61             : PRINT ARG=mv.moment-2,mv.moment-3 FILE=colvar
      62             : ```
