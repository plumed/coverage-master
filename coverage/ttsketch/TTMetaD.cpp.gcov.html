      30             : Performs metadynamics with a tensor-train representation of the bias potential.
      31             : 
      32             : This action runs metadynamics while periodically compressing the accumulated
      33             : Gaussian hills into a low-rank tensor train (TT) using the TT-Sketch algorithm.
      34             : The TT representation keeps memory and evaluation cost bounded throughout long
      35             : simulations, in contrast to standard metadynamics where cost grows linearly with
      36             : the number of deposited hills.
      37             : 
      38             : The basis functions of each argument are defined on [INTERVAL_MIN, INTERVAL_MAX] and are
      39             : periodic over this interval. For a periodic argument the interval should thus coincide with the
      40             : periodicity domain. For a non periodic argument the interval should contain the region that is
      41             : explored: outside it the bias is the one at the closest limit and there is no biasing force along
      42             : that argument, and hills deposited outside are folded back into the interval when they are
      43             : compressed into the TT (a warning is written in the log).
      44             : 
      45             : After every compression the TT is appended to the HDF5 file given by TT_FILE, and the hills file
      46             : restarts empty. When restarting, the last TT in TT_FILE is read back together with the hills in FILE,
      47             : i.e. those deposited after it. With multiple replicas each replica has its own TT_FILE (with the
      48             : replica suffix), unless WALKERS_MPI is used, in which case the walkers share one TT_FILE next to
      49             : the shared hills file. Two TTMETAD actions must use different TT_FILE.
      50             : 
      51             : The hills that are not yet compressed into the TT are truncated as in [METAD](METAD.md): at
      52             : $\sqrt{2\cdot 6.25}$ widths, and stretched so that they go to zero there, so that the bias and the
      53             : forces are continuous (the environment variable `PLUMED_DP2CUTOFF_NOSTRETCH` switches the stretching off).
      54             : 
      55             : ## Choosing the sketch parameters
      56             : 
      57             : The method is discussed in the paper cited below. The values in parentheses are those used there for peptides biased along 2 to 14 backbone dihedral angles.
      58             : 
      59             : - SKETCH_NBASIS sets the resolution of the bias. The Fourier basis (the default) contains harmonics up to $(n-1)/2$, so its shortest wavelength is $2L/(n-1)$, where $L$ is INTERVAL_MAX-INTERVAL_MIN. This should be comparable to SIGMA (31 basis functions on $[-\pi,\pi]$, i.e. a shortest wavelength of 0.42 rad, with SIGMA between 0.25 and 0.4 rad).

It grows when new minima are found and decreases as the bias converges, so final ranks (written in the log after every compression) that no longer change are a sign of convergence.

Use the largest value that does not delay the first barrier crossings in short test runs, between zero and SIGMA (0.05 rad with 6 or more CVs, zero with 2 CVs).
