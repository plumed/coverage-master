      29             : Performs metadynamics with a tensor-train representation of the bias potential.
      30             : 
      31             : This action runs metadynamics while periodically compressing the accumulated
      32             : Gaussian hills into a low-rank tensor train (TT) using the TT-Sketch algorithm.
      33             : The TT representation keeps memory and evaluation cost bounded throughout long
      34             : simulations, in contrast to standard metadynamics where cost grows linearly with
      35             : the number of deposited hills.
      36             : 
      37             : The basis functions of each argument are defined on [INTERVAL_MIN, INTERVAL_MAX] and are
      38             : periodic over this interval. For a periodic argument the interval should thus coincide with the
      39             : periodicity domain. For a non periodic argument the interval should contain the region that is
      40             : explored: outside it the bias is the one at the closest limit and there is no biasing force along
      41             : that argument, and hills deposited outside are folded back into the interval when they are
      42             : compressed into the TT (a warning is written in the log).
      43             : 
      44             : After every compression the TT is appended to the HDF5 file given by TT_FILE, and the hills file
      45             : restarts empty. When restarting, the last TT in TT_FILE is read back together with the hills in FILE,

      49             : 
      50             : The hills that are not yet compressed into the TT are truncated as in [METAD](METAD.md): at
      51             : $\sqrt{2\cdot 6.25}$ widths, and stretched so that they go to zero there, so that the bias and the
