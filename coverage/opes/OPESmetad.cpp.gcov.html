      31             : On-the-fly probability enhanced sampling with metadynamics-like target distribution.
      32             : 
      33             : This On-the-fly probability enhanced sampling (see [OPES](module_opes.md)) method with metadynamics-like target distribution is described in the first paper cited below.
      34             : 
      35             : This OPES_METAD action samples target distributions defined via their marginal $p^{\text{tg}}(\mathbf{s})$ over some collective variables (CVs), $\mathbf{s}=\mathbf{s}(\mathbf{x})$.
      36             : By default OPES_METAD targets the well-tempered distribution, $p^{\text{WT}}(\mathbf{s})\propto [P(\mathbf{s})]^{1/\gamma}$, where $\gamma$ is known as BIASFACTOR.
      37             : Similarly to [METAD](METAD.md), OPES_METAD optimizes the bias on-the-fly, with a given PACE.
      38             : It does so by reweighting via kernel density estimation the unbiased distribution in the CV space, $P(\mathbf{s})$.
      39             : A compression algorithm is used to prevent the number of kernels from growing linearly with the simulation time.
      40             : The bias at step $n$ is
      41             : 
      42             : $$
      43             : V_n(\mathbf{s}) = (1-1/\gamma)\frac{1}{\beta}\log\left(\frac{P_n(\mathbf{s})}{Z_n}+\epsilon\right)\, .
      44             : $$
      45             : 
      46             : See the first paper cited below for a complete description of the method.
      47             : 
      48             : As an intuitive picture, rather than gradually filling the metastable basins, OPES_METAD quickly tries to get a coarse idea of the full free energy surface (FES), and then slowly refines its details.
      49             : It has a fast initial exploration phase, and then becomes extremely conservative and does not significantly change the shape of the deposited bias any more, reaching a regime of quasi-static bias.
      50             : For this reason, it is possible to use standard umbrella sampling reweighting (see [REWEIGHT_BIAS](REWEIGHT_BIAS.md)) to analyse the trajectory.
      51             : At <a href="https://github.com/invemichele/opes/tree/master/postprocessing">this link</a> you can find some python scripts that work in a similar way to [sum_hills](sum_hills.md), but the preferred way to obtain a FES with OPES is via reweighting
      52             : (this is discussed in the tutorials you can access by clicking the button above).
      53             : The estimated $c(t)$ is printed for reference only, since it should converge to a fixed value as the bias converges.
      54             : This $c(t)$ should NOT be used for reweighting.
      55             : Similarly, the $Z_n$ factor is printed only for reference, and it should converge when no new region of the CV-space is explored.
      56             : 
      57             : Notice that OPES_METAD is more sensitive to degenerate CVs than [METAD](METAD.md).
      58             : If the employed CVs map different metastable basins onto the same CV-space region, then OPES_METAD will remain stuck rather than completely reshaping the bias.
      59             : This can be useful to diagnose problems with your collective variable.
      60             : If it is not possible to improve the set of CVs and remove this degeneracy, then you might instead consider to use [OPES_METAD_EXPLORE](OPES_METAD_EXPLORE.md) or [METAD](METAD.md).
      61             : In this way you will be able to obtain an estimate of the FES, but be aware that you most likely will not reach convergence and thus this estimate will be subjected to systematic errors (see e.g. Fig.3 in the second paper cited below).
      62             : On the contrary, if your CVs are not degenerate but only suboptimal, you should converge faster by using OPES_METAD instead of [METAD](METAD.md) as discussed in the first paper cited below.
      63             : 
      64             : The parameter BARRIER should be set to be at least equal to the highest free energy barrier you wish to overcome.
      65             : If it is much lower than that, you will not cross the barrier, if it is much higher, convergence might take a little longer.
      66             : If the system has a basin that is clearly more stable than the others, it is better to start the simulation from there.
      67             : 
      68             : By default, the kernels SIGMA is adaptive, estimated from the fluctuations over ADAPTIVE_SIGMA_STRIDE simulation steps (similar to [METAD](METAD.md) ADAPTIVE=DIFF, but contrary to that, no artifacts are introduced and the bias will converge to the correct one).
      69             : However, notice that depending on the system this might not be the optimal choice for SIGMA.
      70             : 
      71             : The kernels are Gaussians truncated at KERNEL_CUTOFF, in units of SIGMA.
      72             : They are force-shifted, so that both their value and their derivative go to zero at the cutoff.
      73             : At a distance $r$ from its center, in units of SIGMA, a kernel is proportional to $e^{-r^2/2}-c\,\big(1+(r_c^2-r^2)/2\big)$, where $r_c$ is the cutoff and $c=e^{-r_c^2/2}$, and it is zero beyond the cutoff.
      74             : The default cutoff is set from BARRIER, and the kernels then differ from Gaussians only in their far tails.
      75             : 
      76             : The kernels are summed using a neighbor list, which is rebuilt before any kernel outside it can get within the cutoff.
      77             : The result is the same as when summing all the kernels, and with two or more CVs it is usually much faster.
      78             : The neighbor list can be switched off with NLIST_OFF.
      79             : 
      80             : You can target a uniform flat distribution by explicitly setting BIASFACTOR=inf.
      81             : However, this should be useful only in very specific cases.
      82             : 
      83             : It is possible to take into account also of other bias potentials besides the one of OPES_METAD during the internal reweighting for \f$P(\mathbf{s})\f$ estimation.
      84             : To do so, one has to add those biases with the EXTRA_BIAS keyword, as in the example below.
      85             : This allows one to define a custom target distribution by adding another bias potential equal to the desired target free energy and setting BIASFACTOR=inf (see example below).
      86             : Another possible usage of EXTRA_BIAS is to make sure that OPES_METAD does not push against another fixed bias added to restrain the CVs range (e.g. [UPPER_WALLS](UPPER_WALLS.md)).
      87             : 
      88             : Through the EXCLUDED_REGION keywork, it is possible to specify a region of CV space where no kernels will be deposited.
      89             : This can be useful for example for making sure the bias does not modify the transition region, thus allowing for rate calculation.
      90             : See below for an example of how to use this keyword.
      91             : 
      92             : Restart can be done from a KERNELS file, but it might be not perfect (due to limited precision when printing kernels to file, or if adaptive SIGMA is used).
      93             : For an exact restart you must use STATE_RFILE to read a checkpoint with all the needed info.
      94             : To save such checkpoints, define a STATE_WFILE and choose how often to print them with STATE_WSTRIDE.
      95             : By default this file is overwritten, but you can instead append to it using the flag STORE_STATES.
      96             : 
      97             : To continue a simulation with a static bias, for example once the bias has converged, restart from the STATE file and add UPDATE_UNTIL=0.
      98             : No new kernels are then deposited, and the bias remains the one read from STATE_RFILE (no STATE_WFILE is needed).
      99             : 
     100             : Multiple walkers are supported only with MPI communication, via the keyword WALKERS_MPI.
     101             : 
     102             : For synchronized beads of one ring polymer, WALKERS_SHARED_BIAS selects the
     103             : common log weight `mean_b(B(s_b)+EXTRA_BIAS_b)/kBT`, before exponentiation.
     104             : Use it only when the sampled bias Hamiltonian is that same bead average.
     105             : With a bead-local wall, define the wall before OPES and include its `.bias` in
     106             : EXTRA_BIAS to estimate the wall-free marginal; omit it to retain the wall in
     107             : the target ensemble. This option changes deposition weights, not bias forces.
     108             : It requires WALKERS_MPI, explicit SIGMA, equal temperatures and PACE, no
     109             : EXCLUDED_REGION, and synchronized updates on every bead. It is not available
     110             : for OPES_METAD_EXPLORE. Each bead still deposits a kernel, so the kernel counter

     112             : The constant number of beads cancels between the KDE numerator and denominator.
     113             : A STATE or KERNELS history records this mode and bead count; changing either
