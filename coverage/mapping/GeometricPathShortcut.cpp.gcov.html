      26             : //+PLUMEDOC COLVAR GPATH
      27             : /*
      28             : Distance along and from a path calculated using geometric formulas
      29             : 
      30             : The Path Collective Variables developed by Branduardi and that are described in the first paper that is cited below alow one
      31             : to compute the progress along a high-dimensional path and the distance from the high-dimensional path.  The method introduced in that
      32             : paper is implemented in the shortcut [PATH](PATH.md). This action provides an implementation of the alternative method for calculating
      33             : the position on and distance from the path that was proposed by Diaz Leines and Ensing in the second paper that is cited below.  In their
      34             : method, the progress along the path $s$ is calculated using:
      35             : 
      36             : $$
      37             : s = i_2 + \textrm{sign}(i_2-i_1) \frac{ \sqrt{( \mathbf{v}_1\cdot\mathbf{v}_2 )^2 - |\mathbf{v}_3|^2(|\mathbf{v}_1|^2 - |\mathbf{v}_2|^2) } }{2|\mathbf{v}_3|^2} - \frac{\mathbf{v}_1\cdot\mathbf{v}_3 - |\mathbf{v}_3|^2}{2|\mathbf{v}_3|^2}
      38             : $$
      39             : 
      40             : where $\mathbf{v}_1$ and $\mathbf{v}_3$ are the vectors connecting the current position to the closest and second closest node of the path,
      41             : respectfully and $i_1$ and $i_2$ are the projections of the closest and second closest frames of the path. $\mathbf{v}_2$, meanwhile, is the
      42             : vector connecting the closest frame to the second closest frame.  The distance from the path, $z$ is calculated using:
      43             : 
      44             : $$
      45             : z = \sqrt{ \left[ |\mathbf{v}_1|^2 - |\mathbf{v}_2| \left( \frac{ \sqrt{( \mathbf{v}_1\cdot\mathbf{v}_2 )^2 - |\mathbf{v}_3|^2(|\mathbf{v}_1|^2 - |\mathbf{v}_2|^2) } }{2|\mathbf{v}_3|^2} - \frac{\mathbf{v}_1\cdot\mathbf{v}_3 - |\mathbf{v}_3|^2}{2|\mathbf{v}_3|^2} \right) \right]^2 }
      46             : $$
      47             : 
      48             : The symbols here are as they were for $s$.
      49             : 
      50             : ## Examples
      51             : 
      52             : The example input below shows how to use this shortcut.
      53             : 
      54             : ```plumed
      55             : #SETTINGS INPUTFILES=regtest/mapping/rt-adapt/mypath.pdb
      56             : d1: DISTANCE ATOMS=1,2 COMPONENTS
      57             : pp: GPATH ...
      58             :    ARG=d1.x,d1.y PROPERTY=path
      59             :    REFERENCE=regtest/mapping/rt-adapt/mypath.pdb
      60             : ...
      61             : PRINT ARG=d1.x,d1.y,pp.* FILE=colvar
      62             : ```
      63             : 
      64             : The curved path here is defined using a series of points in a two dimensional space.  Furthermore, the coordinates that these points should be projected at on the low dimensional path
      65             : (the $i$ values in the equation for $s$ above) are specified in the `path` property of the input pdb file.
      66             : 
      67             : The input below illustrates how to the positions of atoms to define the path:
      68             : 
      69             : ```plumed
      70             : ##SETTINGS INPUTFILES=regtest/trajectories/path_msd/all.pdb
      71             : p1b: GPATH REFERENCE=regtest/trajectories/path_msd/all.pdb
      72             : PRINT ARG=p1b.* FILE=colvar_b STRIDE=1
      73             : ```
      74             : 
      75             : When an input like the one above is used the vectors $\mathbf{v}_1$, $\mathbf{v}_2$ and $\mathbf{v}_3$ from the expression above are computed using an [RMSD](RMSD.md)
      76             : action with the DISPLACEMENT flag enabled.  The instaneous structure is thus aligned with the reference structures so as to remove motions due to translation of the center
      77             : of mass and rotation of the reference frame.  Furthermore, because we have not used the PROPERTY keyword in this input, the $i$ values in the equation for $s$
      78             : above are set equal to 1, 2, 3...
      79             : 
      80             : */
