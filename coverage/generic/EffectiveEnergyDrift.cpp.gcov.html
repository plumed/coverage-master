      52             : The method that is used to calculate the effective energy drift here is described in the

      54             : 
      55             : ## Examples
      56             : 
      57             : This input is to monitor the effective energy drift for a metadynamics
      58             : simulation on the Debye-Huckel energy. Since this variable is very expensive,
      59             : it could be conveniently computed every second step.
      60             : 
      61             : ```plumed
      62             : dh: DHENERGY GROUPA=1-10 GROUPB=11-20 EPSILON=80.0 I=0.1 TEMP=300.0
      63             : METAD ARG=dh HEIGHT=0.5 SIGMA=0.1 PACE=500 STRIDE=2
      64             : EFFECTIVE_ENERGY_DRIFT PRINT_STRIDE=100 FILE=eff
      65             : ```
      66             : 
      67             : This exampls shows how to monitor if a restraint is too stiff
      68             : 
      69             : ```plumed
      70             : d: DISTANCE ATOMS=10,20
      71             : RESTRAINT ARG=d KAPPA=100000 AT=0.6
      72             : EFFECTIVE_ENERGY_DRIFT PRINT_STRIDE=100 FILE=eff
      73             : ```
      74             : 
      75             : ## Restart
      76             : 
      77             : With [CHECKPOINT](CHECKPOINT.md) the drift and the positions and forces of the previous step are stored in the checkpoint. With a single process the restart is exact. With more processes the data of all the processes is gathered in the checkpoint and redistributed at the restart, which may also use a different number of processes or a different domain decomposition: the drift is the same up to the rounding of the sum over the processes.
