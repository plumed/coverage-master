      41             : //+PLUMEDOC GENERIC WRAPAROUND
      42             : /*
      43             : Rebuild periodic boundary conditions around chosen atoms.
      44             : 
      45             : This action modifies the position of the atoms indicated by ATOMS by shifting them by lattice vectors so that they are
      46             : as close as possible to the atoms indicated by AROUND. More precisely, for every atom i
      47             : in the ATOMS list the following procedure is performed:
      48             : - The atom j among those in the AROUND list is searched that is closest to atom i.
      49             : - The atom i is replaced with its periodic image that is closest to atom j.
      50             : 
      51             : This action works similarly to [WHOLEMOLECULES](WHOLEMOLECULES.md) in that it replaces atoms coordinate. Notice that only
      52             : atoms specified with ATOMS are replaced, and that, at variance with [WHOLEMOLECULES](WHOLEMOLECULES.md),
      53             : the order in which atoms are specified is irrelevant.
      54             : 
      55             : This is often convenient at a post processing stage (using the driver), but sometime
      56             : it is required during the simulation if collective variables need atoms to be in a specific periodic image.
      57             : 
      58             : !!! caution "modifies stored positions
      59             : 
      60             :     This directive modifies the stored position at the precise moment it is executed. This means that only collective variables which are below it in
      61             :     the input script will see the corrected positions. As a general rule, put it at the top of the input file. Also, unless you know exactly what you are doing,
      62             :     leave the default stride (1), so that this action is performed at every MD step.
      63             : 
      64             : The computational cost of this action grows with the product
      65             : of the size of the two lists (ATOMS and AROUND), so this action can become very expensive.
      66             : If you are using it to analyze a trajectory this is usually not a big problem. If you use it to
      67             : analyze a simulation on the fly, e.g. with [DUMPATOMS](DUMPATOMS.md) to store a properly wrapped trajectory,
      68             : consider using the STRIDE keyword here (with great care).
      69             : 
      70             : 
      71             : ## Examples
      72             : 
      73             : This command instructs plumed to move all the ions to their periodic image that is as close as possible to
      74             : the rna group.
      75             : 
      76             : ```plumed
      77             : rna: GROUP ATOMS=1-100
      78             : ions: GROUP ATOMS=101-110
      79             : # first make the rna molecule whole
      80             : WHOLEMOLECULES ENTITY0=rna
      81             : WRAPAROUND ATOMS=ions AROUND=rna
      82             : DUMPATOMS FILE=dump.xyz ATOMS=rna,ions
      83             : ```
      84             : 
      85             : In case you want to do it during a simulation and you only care about wrapping the ions in
      86             : the `dump.xyz` file, you can use the following input:
      87             : 
      88             : ```plumed
      89             : # add some restraint that do not require molecules to be whole:
      90             : a: TORSION ATOMS=1,2,10,11
      91             : RESTRAINT ARG=a AT=0.0 KAPPA=5
      92             : 
      93             : 
      94             : # then do the things that are required for dumping the trajectory
      95             : # notice that they are all done every 100 steps, so as not to
      96             : # unnecessarily overload the calculation
      97             : 
      98             : rna: GROUP ATOMS=1-100
      99             : ions: GROUP ATOMS=101-110
     100             : # first make the rna molecule whole
     101             : WHOLEMOLECULES ENTITY0=rna STRIDE=100
     102             : WRAPAROUND ATOMS=ions AROUND=rna STRIDE=100
     103             : DUMPATOMS FILE=dump.xyz ATOMS=rna,ions STRIDE=100
     104             : ```
     105             : 
     106             : Notice that if the biased variable requires a molecule to be whole, you might have to put
     107             : the [WHOLEMOLECULES](WHOLEMOLECULES.md) command before computing that variable and leave the default STRIDE=1.
     108             : 
     109             : This command instructs plumed to center all atoms around the center of mass of a solute molecule.
     110             : 
     111             : ```plumed
     112             : solute: GROUP ATOMS=1-100
     113             : all: GROUP ATOMS=1-1000
     114             : # center of the solute:
     115             : # notice that since plumed 2.2 this also works if the
     116             : # solute molecule is broken
     117             : com: COM ATOMS=solute
     118             : # notice that we wrap around a single atom. this should be fast
     119             : WRAPAROUND ATOMS=all AROUND=com
     120             : DUMPATOMS FILE=dump.xyz ATOMS=all
     121             : ```
     122             : 
     123             : Notice that whereas [WHOLEMOLECULES](WHOLEMOLECULES.md) is designed to make molecules whole,
     124             : WRAPAROUND can easily break molecules. In the last example,
     125             : if solvent (atoms 101-1000) is made e.g. of water, then water
     126             : molecules could be broken by WRAPAROUND (hydrogen could end up
     127             : in an image and oxygen in another one).
     128             : One solution is to use [WHOLEMOLECULES](WHOLEMOLECULES.md) on _all_ the water molecules
     129             : after WRAPAROUND. This is tedious. A better solution is to use the
     130             : GROUPBY option which is going
     131             : to consider the atoms listed in ATOMS as a list of groups
     132             : each of size GROUPBY. The first atom of the group will be brought
     133             : close to the AROUND atoms. The following atoms of the group
     134             : will be just brought close to the first atom of the group.
     135             : Assuming that oxygen is the first atom of each water molecules,
     136             : in the following examples all the water oxygen atoms will be brought
     137             : close to the solute, and all the hydrogen atoms will be kept close
     138             : to their related oxygen.
     139             : 
     140             : ```plumed
     141             : solute: GROUP ATOMS=1-100
     142             : water: GROUP ATOMS=101-1000
     143             : com: COM ATOMS=solute
     144             : # notice that we wrap around a single atom. this should be fast
     145             : WRAPAROUND ATOMS=solute AROUND=com
     146             : # notice that we wrap around a single atom. this should be fast
     147             : WRAPAROUND ATOMS=water AROUND=com GROUPBY=3
     148             : DUMPATOMS FILE=dump.xyz ATOMS=solute,water
     149             : ```

     151             : */
