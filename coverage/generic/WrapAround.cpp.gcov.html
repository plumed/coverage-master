      46             : //+PLUMEDOC GENERIC WRAPAROUND
      47             : /*
      48             : Rebuild periodic boundary conditions around chosen atoms.
      49             : 
      50             : This action modifies the position of the atoms indicated by ATOMS by shifting them by lattice vectors so that they are
      51             : as close as possible to the atoms indicated by AROUND. More precisely, for every atom i
      52             : in the ATOMS list the following procedure is performed:
      53             : - The atom j among those in the AROUND list is searched that is closest to atom i.
      54             : - The atom i is replaced with its periodic image that is closest to atom j.
      55             : 
      56             : This action works similarly to [WHOLEMOLECULES](WHOLEMOLECULES.md) in that it replaces atoms coordinate. Notice that only
      57             : atoms specified with ATOMS are replaced, and that, at variance with [WHOLEMOLECULES](WHOLEMOLECULES.md),
      58             : the order in which atoms are specified is irrelevant when grouping and PAIR are not used.
      59             : 
      60             : This is often convenient at a post processing stage (using the driver), but sometime
      61             : it is required during the simulation if collective variables need atoms to be in a specific periodic image.
      62             : 
      63             : !!! caution "modifies stored positions
      64             : 
      65             :     This directive modifies the stored position at the precise moment it is executed. This means that only collective variables which are below it in
      66             :     the input script will see the corrected positions. As a general rule, put it at the top of the input file. Also, unless you know exactly what you are doing,
      67             :     leave the default stride (1), so that this action is performed at every MD step.
      68             : 
      69             : This action searches the reference list once per atom or group. Large AROUND
      70             : lists use a cell search; smaller lists are searched directly. Reconstructing
      71             : residue batches and computing their centers takes linear work in the number
      72             : of selected atoms. Large selections can still be expensive.
      73             : If you are using it to analyze a trajectory this is usually not a big problem. If you use it to
      74             : analyze a simulation on the fly, e.g. with [DUMPATOMS](DUMPATOMS.md) to store a properly wrapped trajectory,
      75             : consider using the STRIDE keyword here (with great care).
      76             : 
      77             : 
      78             : ## Examples
      79             : 
      80             : This command instructs plumed to move all the ions to their periodic image that is as close as possible to
      81             : the rna group.
      82             : 
      83             : ```plumed
      84             : rna: GROUP ATOMS=1-100
      85             : ions: GROUP ATOMS=101-110
      86             : # first make the rna molecule whole
      87             : WHOLEMOLECULES ENTITY0=rna
      88             : WRAPAROUND ATOMS=ions AROUND=rna
      89             : DUMPATOMS FILE=dump.xyz ATOMS=rna,ions
      90             : ```
      91             : 
      92             : In case you want to do it during a simulation and you only care about wrapping the ions in
      93             : the `dump.xyz` file, you can use the following input:
      94             : 
      95             : ```plumed
      96             : # add some restraint that do not require molecules to be whole:
      97             : a: TORSION ATOMS=1,2,10,11
      98             : RESTRAINT ARG=a AT=0.0 KAPPA=5
      99             : 
     100             : 
     101             : # then do the things that are required for dumping the trajectory
     102             : # notice that they are all done every 100 steps, so as not to
     103             : # unnecessarily overload the calculation
     104             : 
     105             : rna: GROUP ATOMS=1-100
     106             : ions: GROUP ATOMS=101-110
     107             : # first make the rna molecule whole
     108             : WHOLEMOLECULES ENTITY0=rna STRIDE=100
     109             : WRAPAROUND ATOMS=ions AROUND=rna STRIDE=100
     110             : DUMPATOMS FILE=dump.xyz ATOMS=rna,ions STRIDE=100
     111             : ```
     112             : 
     113             : Notice that if the biased variable requires a molecule to be whole, you might have to put
     114             : the [WHOLEMOLECULES](WHOLEMOLECULES.md) command before computing that variable and leave the default STRIDE=1.
     115             : 
     116             : This command instructs plumed to center all atoms around the center of mass of a solute molecule.
     117             : 
     118             : ```plumed
     119             : solute: GROUP ATOMS=1-100
     120             : all: GROUP ATOMS=1-1000
     121             : # center of the solute:
     122             : # notice that since plumed 2.2 this also works if the
     123             : # solute molecule is broken
     124             : com: COM ATOMS=solute
     125             : # notice that we wrap around a single atom. this should be fast
     126             : WRAPAROUND ATOMS=all AROUND=com
     127             : DUMPATOMS FILE=dump.xyz ATOMS=all
     128             : ```
     129             : 
     130             : Notice that whereas [WHOLEMOLECULES](WHOLEMOLECULES.md) is designed to make molecules whole,
     131             : WRAPAROUND can easily break molecules. In the last example,
     132             : if solvent (atoms 101-1000) is made e.g. of water, then water
     133             : molecules could be broken by WRAPAROUND (hydrogen could end up
     134             : in an image and oxygen in another one).
     135             : One solution is to use [WHOLEMOLECULES](WHOLEMOLECULES.md) on _all_ the water molecules
     136             : after WRAPAROUND. This is tedious. A better solution is to use the
     137             : GROUPBY option which is going
     138             : to consider the atoms listed in ATOMS as a list of groups
     139             : each of size GROUPBY. The first atom of the group will be brought
     140             : close to the AROUND atoms. The following atoms of the group
     141             : will be just brought close to the first atom of the group.
     142             : Assuming that oxygen is the first atom of each water molecules,
     143             : in the following examples all the water oxygen atoms will be brought
     144             : close to the solute, and all the hydrogen atoms will be kept close
     145             : to their related oxygen.
     146             : 
     147             : ```plumed
     148             : solute: GROUP ATOMS=1-100
     149             : water: GROUP ATOMS=101-1000
     150             : com: COM ATOMS=solute
     151             : # notice that we wrap around a single atom. this should be fast
     152             : WRAPAROUND ATOMS=solute AROUND=com
     153             : # notice that we wrap around a single atom. this should be fast
     154             : WRAPAROUND ATOMS=water AROUND=com GROUPBY=3
     155             : DUMPATOMS FILE=dump.xyz ATOMS=solute,water
     156             : ```
     157             : 
     158             : 
     159             : ## Grouping by residue
     160             : 
     161             : `GROUP_BY_RESIDUE` handles mixed residue sizes in a single selection, for example
     162             : three- and four-site waters and single-atom ions. A preceding MOLINFO supplies
     163             : residue membership only: its reference coordinates and box are ignored. Neither
     164             : WHOLE nor SMALL_RESIDUES is required.
     165             : 
     166             : Duplicate ATOMS entries are removed while retaining their first occurrence.
     167             : Each consecutive run of selected atoms of the same residue forms a batch. The
     168             : metadata distinguishes chain, residue number, insertion code, TER boundaries and
     169             : nonconsecutive occurrences of reused residue identifiers. Partial selections
     170             : include only the selected members. If one residue occurs in separate ATOMS
     171             : runs, those batches are wrapped independently.
     172             : 
     173             : At each active step, the selected atoms in every batch are reconstructed in
     174             : ATOMS order, as with WHOLEMOLECULES without a reference tree. WRAPAROUND computes
     175             : the geometric center of these current whole coordinates, finds its closest
     176             : periodic reference in AROUND, and translates the entire reconstructed batch by
     177             : one lattice vector. This preserves its reconstructed internal geometry.
     178             : 
     179             : ```plumed
     180             : #SETTINGS MOLFILE=regtest/basic/rt-wraparound-residue-centers/metadata.pdb
     181             : MOLINFO STRUCTURE=regtest/basic/rt-wraparound-residue-centers/metadata.pdb
     182             : solute: GROUP ATOMS=1-3
     183             : solvent: GROUP ATOMS=4-14
     184             : WHOLEMOLECULES ENTITY0=solute
     185             : WRAPAROUND ATOMS=solvent AROUND=solute GROUP_BY_RESIDUE
     186             : DUMPATOMS ATOMS=solute,solvent FILE=wrapped.xyz
     187             : ```
     188             : 
     189             : Use this option for residues whose selected members can be reconstructed by
     190             : minimum-image links in the supplied ATOMS order. Ordinary compact biomolecular
     191             : residues normally satisfy this condition. It is an explicit grouping request;
     192             : a material encoded as one large residue should use a reconstruction/grouping
     193             : appropriate to that material instead. A multi-residue solute can still be split
     194             : by independently wrapping its residues around a point. To keep it whole, first
     195             : use WHOLEMOLECULES on the solute and wrap solvent around the solute's atoms.
     196             : 
     197             : `PAIR` requires exactly one AROUND entry per batch, matched in batch order, and
     198             : retains repeated AROUND entries. A count mismatch is an error. The default
     199             : `GROUPBY=1`, including an explicit value of 1, is accepted with GROUP_BY_RESIDUE;
     200             : other GROUPBY values conflict. Existing fixed-size GROUPBY behavior is unchanged.
     201             : 
     202             : */
