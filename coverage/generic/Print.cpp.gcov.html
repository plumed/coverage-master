     102             : appended or backed up depends on whetehr or not the [RESTART](RESTART.md) action is present on the file. If you add `RESTART=yes` on the

     104             : 
     105             : Printing happens in the so-called "update" phase. This implies that printing

     123             : existing file you can use the RESTART command as shown below:

     125             : ```plumed

     139             : 
     140             : ```plumed
     141             : d1: DISTANCE ATOMS=1,2

     145             : ```

     147             : If you use the input above the file `colvar1` is backed up, while new data will be appended to the file `colvar2`.  If you use the
     148             : [RESTART](RESTART.md) action instead data will be appended to both colvar files.
     149             : 
     150             : ## Switching printing on and off

     153             : To see how this works consider the following example:
     154             : 
     155             : ```plumed
