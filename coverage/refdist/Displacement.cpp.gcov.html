      32             : This shortcut can be used to calculate the vector of displacements between two input vectors as shown below.
      33             : 
      34             : ```plumed
      35             : c: CONSTANT VALUES=1,2,3
      36             : d: DISTANCE ATOMS1=1,2 ATOMS2=3,4 ATOMS3=5,6

      40             :

      43             : $$

      45             : $$
      46             : 
      47             : Notice that we can obtain the same result by specifying the input vectors here as two sets of three scalars as shown
      48             : below:
      49             : 
      50             : ```plumed
      51             : c1: CONSTANT VALUE=1
      52             : d1: DISTANCE ATOMS=1,2
      53             : c2: CONSTANT VALUE=2

      55             : c3: CONSTANT VALUE=3
      56             : d3: DISTANCE ATOMS=5,6

      67             : $$

      70             : [NORMALIZED_EUCLIDEAN_DISTANCE](NORMALIZED_EUCLIDEAN_DISTANCE.md) and a full matrix if you are computing the [MAHALANOBIS_DISTANCE](MAHALANOBIS_DISTANCE.md).

      72             : ## Calculating multiple displacement vectors
      73             : 
      74             : The reason the output of DISPLACEMENT is a $1 \times 3$ matrix here becomes clearer once we consider the following input:
      75             : 
      76             : ```plumed
      77             : ref_psi: CONSTANT VALUES=2.25
      78             : ref_phi: CONSTANT VALUES=-1.91
      79             : 
      80             : psi: TORSION ATOMS1=1,2,3,4 ATOMS2=5,6,7,8 ATOMS3=9,10,11,12
      81             : phi: TORSION ATOMS1=13,14,15,16 ATOMS2=17,18,19,20 ATOMS3=21,22,23,24
      82             : 
      83             : dd: DISPLACEMENT ARG1=psi,phi ARG2=ref_psi,ref_phi
      84             : PRINT ARG=dd FILE=colvar
      85             : ```
      86             : 
      87             : The output from the input above is a $3\times 2$ matrix.  The rows of this matrix run over the 3 different
      88             : torsion values that have been specified in the `psi` and `phi` commands.  The first column of the matrix
      89             : contains the differences between each of the instantaneous `psi` aingles and the reference value for this
      90             : angle, while the second columns contains the differences between the `phi` angles and the reference.
      91             : 
      92             : In other words, we can calculate multiple displacement vectors at once as each row of the final output matrix will
      93             : contain a vector of displacements between two vectors.  Notice that we can use a similar input to calculate the
      94             : differences between the instantaneous value of a pair of torsions and 3 reference values as shown below:
      95             :

      97             : ref_psi: CONSTANT VALUES=2.25,1.3,-1.5
      98             : ref_phi: CONSTANT VALUES=-1.91,-0.6,2.4

     100             : psi: TORSION ATOMS=1,2,3,4
     101             : phi: TORSION ATOMS=13,14,15,16

     104             : PRINT ARG=dd FILE=colvar
     105             : ```
     106             : 
     107             : !!! note "scalars must be specified in ARG2"
     108             : 
     109             :     If you use a mixture of vectors are scalars when specifying the input to to this action the
     110             :     vectors should be passed using the ARG1 keyword and the scalars must be passed in the ARG2 keyword
     111             :     as is done in the example inputs above. Obviously, this limitation sometimes means that you have to add in
     112             :     an additional [CUSTOM](CUSTOM.md) action that multiplies the output vectors by -1 to get the vectors pointing
     113             :     in the direction you desire.
     114             : 
     115             : The output here will again be a $3\times 2$ matrix with each of the three rows holding a vector of displacements
     116             : between the 2 instananeous values and one of the three sets of reference values.
     117             : 
     118             : Lastly, we can use two sets of vectors in the input to DISPLACEMENT as shown below:
     119             : 
     120             : ```plumed
     121             : ref_psi: CONSTANT VALUES=2.25,1.3,-1.5
     122             : ref_phi: CONSTANT VALUES=-1.91,-0.6,2.4
     123             : 
     124             : psi: TORSION ATOMS1=1,2,3,4 ATOMS2=5,6,7,8 ATOMS3=9,10,11,12
     125             : phi: TORSION ATOMS1=13,14,15,16 ATOMS2=17,18,19,20 ATOMS3=21,22,23,24

     128             : PRINT ARG=dd FILE=colvar
     129             : ```
     130             : 
     131             : The output here is still a $3 \times 2$ matrix. Now, however, each of the three instantaneous angles we have calculated
     132             : has its own set of reference values. A different pair of instaneous and reference values is used to calculate each element
     133             : of the resulting matrix.
     134             : 
     135             : DISPLACEMENT actions that compute $M\times N$ matrices, $D$, are used within the [EUCLIDEAN_DISTANCE](EUCLIDEAN_DISTANCE.md),
     136             : [NORMALIZED_EUCLIDEAN_DISTANCE](NORMALIZED_EUCLIDEAN_DISTANCE.md) and [MAHALANOBIS_DISTANCE](MAHALANOBIS_DISTANCE.md) shortcuts.
     137             : Doing so is useful as if you take the diagonal elements of a product of matrices that is similar to the product of vectors and matrices that we introduced
     138             : earlier:
     139             : 
     140             : $$
     141             : d = D M D^T
     142             : $$
     143             :
